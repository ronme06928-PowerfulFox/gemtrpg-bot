# 旧データの保管

このフォルダは現行アプリが読み込まない旧資料の保管先です。起動用のマスターは隣の `data/cache/` にあります。

| ファイル | 元の場所 | 保管理由 |
|---|---|---|
| [images.json](images.json) | `data/images.json` | 旧画像登録情報1件。現行コードから未参照と確認し、2026-10-31のユーザー選択1により内容を変えず退避。Git管理対象として保持 |

ルートにあった旧ルーム保存・戦闘状態・ユーザーDBの3本は、Git除外の `_local/legacy_data/2026-10-31/` に原本を保管します。そこには移動元・容量・SHA-256の記録も置きます。使い捨て出力として削除したり、Gitへ追加したりしないでください。

移動内容と検証の記録は[アプリ基盤の課題一覧](../../manuals/projects/app_foundation/backlog.md#repo-legacy-data判断事項)を参照してください。旧データをアプリの読込先へ戻す仕組みや自動移行は設けていません。
