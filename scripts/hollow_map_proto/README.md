# ホロウの地図の画面の試作（計画35 PR35-9）

`node scripts/hollow_map_proto/build.mjs` を実行し、`_local/hollow_map_proto/index.html` をブラウザーで開く。アプリは起動しない。

段の幅・道のつなぎ方・札の位置・マスの種類は種から決める（PR35-9 で `manager/hollow/map.py` をこの形に直す）。道は交差せず、別れ道と合流ができる。部屋の骨組み（見出し・ドック・右の列・チャット）は見本で、地図の画面は `common_ui.css` の `[data-theme="abyss"]` の変数で作る。

右下の切り替え：

- 地図：1段＝1F の帯に、アイコンと種類名の札を並べる。見えるのは今いる階の2段下までで、その先は「未踏」の帯。段の幅（ほとんど2〜3）と札の位置は種から揺らす。
- 切り替え：地図が上へ沈み、「4F 通常戦闘」の幕を挟んで戦闘の画面に移る。マスにカーソルを合わせると「4F 通常戦闘」の札が付き、押すと「入場」「キャンセル」の窓が出る。
- 見る人：ホストは次のマス・撤退・出撃と控えの入れ替えを押せる。プレイヤーは見るだけ。
- 場面：出発前（ランを始める）、3F の後（岩牙が倒れて控えにいる）、9F の後（次がボス）。

戦闘の画面の「勝つ（試作）」「全滅（試作）」で地図や結果に戻る。ボスに勝つと T2 の地図に切り替わる。下の欄に、淵の夜の主な組み合わせのコントラスト（文字 4.5:1・図形 3:1）を出す。

URL の `?viewer=player&scene=boss` でも切り替えられる。

実装の確認は、確認用 DB の写しを `_local/agent_db/gemtrpg.db` に置き、`python -m scripts.hollow_map_check --app-python .venv/Scripts/python.exe` で実行する。実アプリの2人分の状態と写真を確認し、写真を `_local/pr35_9_shots/` に保存する。
