# ユニット管理のデザイン試作

`node scripts/unit_ui_proposals/build.mjs` を実行し、`_local/unit_ui_proposals/index.html` をブラウザで開く。

- 台帳は、左の行一覧、中央のセクション別フォーム、右の確認欄で構成する。スキル候補は行ごとに効果やコストを表示する。
- シートは、左の要約カード、中央の連続フォーム、右の確認欄で構成する。候補は名前の一覧と選択中の詳細を並べる。
- 右下の案切替で、種別・選択・編集中の値・候補の検索条件を維持する。どちらも680pxでは確認欄を編集欄の下に配置する。
- マスターとプリセットは `data/cache/` から読み込む。プリセットを元に試作用のIDを付け、一覧の密度を確認するために派生サンプルも生成する。操作結果はページ内に保持する。
- 比較対象は一覧・フォーム・候補選択・確認・操作帯。取り込み、履歴復元、画像選択、実データへの保存は比較対象外。

Playwright と Chrome が入った環境では、ビルド後に `python scripts/unit_ui_proposals/check.py` で両案の操作と1280px・680pxでの横幅を確認できる。
