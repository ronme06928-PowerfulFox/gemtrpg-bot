# 淵遺物の窓・戦闘の報酬・虚夢変転の試作（計画35 PR35-14）

`node scripts/hollow_relic_proto/build.mjs` を実行し、`_local/hollow_relic_proto/index.html` をブラウザーで開く。アプリは起動しない。

部屋の骨組みは地図の試作（`scripts/hollow_map_proto/page.css`）を使い、足す分だけを `page.css` に置く。淵遺物の見本は設計表（`manuals/planned/35_Hollow_Content_Design.md` §4.3）の出血の遺物ほか。アイコンは絵が無いときの仮の形（カテゴリの色の宝玉とランク、代償つきは左上の赤い点）。

右下の切り替え：

- 見る人：ホストは報酬を選び、虚夢変転を行う。プレイヤーは見るだけ（「ホストが選んでいます」）。
- 場面：
  - 報酬：盤面の場所に候補3つの札。札は大きなアイコン・名前・カテゴリ・ランク・効果・代償・魔力負荷の増え方。所持済みは「素材になる」の印。札を選んで「受け取る」か「見送る」。
  - 虚夢変転：左に所持の淵遺物と汎用素材、右に材料の枠（2〜4）。ランクの計算とカテゴリの見込み（材料の割合）を出し、特別な組み合わせに当てはまると「特別な遺物ができる気配がある」と予告する。祈念で11カテゴリから選べる。見本の特別な組み合わせは「止血帯の切れ端＋裂け目の縫い針」。
- 窓：淵遺物の窓（ドックの宝玉のアイコンからも開く）。魔力負荷の値・段階の目盛り・各段階の代償、所持のアイコンの格子、押すと右に詳しい中身、汎用素材、一時バフ。

URL の `?viewer=player&screen=fusion` でも切り替えられる。
