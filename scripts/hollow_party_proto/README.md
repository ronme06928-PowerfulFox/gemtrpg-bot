右下の切り替え：

- 並べ替え：A は各行の「↑」「↓」。B は行をつかんで動かす（つまみに合わせて上下の矢印キーでも動く）。
- 見る人：リオ（オーナー）・ナギ・トウカ。ホスト本人とオーナーだけが並べ替え・加える・外す・ホストを譲るを押せる。プレイヤーは自分のキャラの「アイテム」だけ押せる。
- 状態：ラン中は並びが固定になる。「作成直後の窓」で部屋を作った直後の参加コードの窓を開く。
- 下の欄に、淵の夜の主な組み合わせのコントラスト（文字 4.5:1・枠 3:1）を出す。

実装後の確認は、確認用の DB の写しを `_local/agent_db/gemtrpg.db` に用意して `python -m scripts.hollow_party_proto.check_app --app-python .venv/Scripts/python.exe` を実行する。3人で実アプリを操作し、写真を `_local/pr35_6_shots/` に保存する。確認後は写しを片付ける。
