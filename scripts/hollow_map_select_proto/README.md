# マップの選択とパーティメンバーの追加の試作（計画35 PR35-11）

`node scripts/hollow_map_select_proto/build.mjs` を実行し、`_local/hollow_map_select_proto/index.html` をブラウザーで開く。アプリは起動しない。

部屋の骨組みは地図の試作（`scripts/hollow_map_proto/page.css`）を使い、足す分だけを `page.css` に置く。マップの絵は同じ洞窟の絵の色相をずらした仮のもの。データは見本。

右下の切り替え：

- 見る人：ホストは札を押して「このマップへ進む」の窓を開ける。プレイヤーは見るだけ（「ホストがマップを選んでいます」）。
- 場面：ランの始め（T1）と、10F のボスの後（T2）。
- 並べ方：A は札を横に3枚。B は左に一覧、右に選んだマップの詳細。
- 手がかり：多めは、出やすい淵遺物のカテゴリ・出る敵の顔と等級・区切りの主の影。少なめは、説明とカテゴリだけ。
- ドック：ホロウ用は「簡易ステータス編集」「未配置キャラクター」を隠し、「＋」を「パーティメンバーを追加」にする。「今」は隠すアイコンを赤い破線で示す。
- 窓：「パーティメンバーを追加」。ドックの「＋」からも開く。自分の持ちキャラから選び、パーティにいるキャラは選べない。空きの数を超えて選べない。

URL の `?viewer=player&scene=start&layout=list&hints=few&dock=now` でも切り替えられる。
