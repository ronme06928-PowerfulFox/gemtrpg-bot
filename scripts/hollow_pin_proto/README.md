# 推薦ピンの試作（計画35 PR35-18）

`node scripts/hollow_pin_proto/build.mjs` を実行し、`_local/hollow_pin_proto/index.html` をブラウザーで開く。アプリは起動しない。

地図・マップを選ぶ・淵遺物・イベント階の試作の CSS（`scripts/hollow_map_proto/`・`hollow_map_select_proto/`・`hollow_relic_proto/`・`hollow_event_proto/` の `page.css`）を使い、足す分だけを `page.css` に置く。参加者は見本（ホストのリオ、プレイヤーのミナ・カイ・セラ）。

- プレイヤーは札を押すとピンを立て、もう一度押すと外す。別の札を押すと移る（1つの場面で1人1本）。
- ホストはピンを立てず、札を押すと選ぶ。決めると、その場面のピンが消える。
- 印は人（アカウント）の頭文字と色。自分の印は縁を明るくする。

右下の切り替え：

- 見る人：プレイヤー（ミナ）／ホスト（リオ）
- 場面：次のマス・撤退（地図のマスと撤退のボタン）、マップを選ぶ、報酬（候補と見送る）、魔素だまり（選択肢）、宝箱（受け取る・見送る）
- ピンの形：A は札の右上に顔の丸を重ねる、B は札の下（マスでは下、選択肢では右端）に「ピン 名前」の帯
- 試す：ほかの人のピンを動かす、全部外す

URL の `?scene=reward&viewer=host&pinstyle=names` でも切り替えられる。
