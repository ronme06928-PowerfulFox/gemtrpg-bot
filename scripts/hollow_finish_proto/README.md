# ホロウの仕上げの試作（計画35 PR35-19）

`node scripts/hollow_finish_proto/build.mjs` を実行し、`_local/hollow_finish_proto/index.html` をブラウザーで開く。アプリは起動しない。

部屋の骨組みは地図の試作（`scripts/hollow_map_proto/page.css`）を使い、足す分だけを `page.css` に置く。地図は T5（41〜50F）の見本で、今いる階の2段下までが見え、その先は未踏の段。

右下の切り替え：

- 場面：44F の地図、49F の後（次がボス）
- 霧：A は淡い霧がゆっくり横へ流れる。B は厚い霧で、見えている段との境目に淡い光の筋。
- 封鎖：「50F のボスに勝つ」で再生する。どちらも「50F 制圧」の幕の後に封鎖を見せ、ランの結果（クリア）へ移る。
  - A は地図の 50F の下に 51F の段が現れ、結晶の壁がせり上がって「深層 · 封鎖」と出る。
  - B は盤面いっぱいの幕で、縦穴を見下ろす光の上に紋章の輪が描かれ、「深層への道は、閉ざされている」「浅層 踏破」と出る。
- C 高解像度（`hd.js`、コードだけで描く。開いたときの既定）：
  - 霧：ノイズで作った霧の画像を遠い・中・近い3層にして違う速さで流し、霧の奥でときどき鉱石の光が透ける。1段進むと、晴れる段の霧が中央から左右へ割れて引いていく。
  - 封鎖：奥へ続く通路（床・壁・天井を遠近で描き、奥ほど明るい）の先に縦長の昏い光の口があり、床へ光がこぼれる。その手前へ、通路の壁から生える奥の岩（根元は透明へ溶ける）、続いて画面の端や下から宝石まじりの暗い岩が勢いよく突き出して塞ぐ（画面の揺れと欠片）。岩は尾根と面に分け、奥の光の向きで面ごとに明暗を付ける。初めは奥へ歩いていく視点（少しずつ近づき、歩みで揺れる）で、奥の岩が出ると歩みが鈍り、手前の岩が突き出すと立ち止まって半歩押し戻される。「浅層踏破」を大きく出し、続いて「虚夢の深淵、／未だ立ち入る資格なし」を二行で出してから、ランの結果へ移る（約14秒、押すと飛ばせる）。
- 右の列：A は今の帯（状態・ホスト・人数・参加コード）。B は深度計（今の階と Tier・マップの名前、1〜50F を T1〜T5 の5つの目盛りで塗り、今の階に印。魔力負荷と段階・人数・参加コード）。
- 試す：「1段進む」で今の階が1つ下がり、霧が1段晴れて札が現れる。

動きを減らす設定では、霧の流れと封鎖の動きを止める。

URL の `?scene=boss&fog=veil&seal=curtain&strip=plain` でも切り替えられる。
