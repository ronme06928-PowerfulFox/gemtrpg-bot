# イベント階の画面とホロウデータのタブの試作（計画35 PR35-16）

`node scripts/hollow_event_proto/build.mjs` を実行し、`_local/hollow_event_proto/index.html` をブラウザーで開く。アプリは起動しない。

部屋の骨組みは地図の試作（`scripts/hollow_map_proto/page.css`）、淵遺物の札とアイコンは淵遺物の試作（`scripts/hollow_relic_proto/page.css`）を使い、足す分だけを `page.css` に置く。データは見本。

右下の切り替え：

- 見る人：ホストは選択肢・人・受け取るかを選ぶ。プレイヤーは見るだけ（「ホストが選んでいます」）。結果・町・キャンプの「閉じる」は各自の画面で閉じる。
- 場面：
  - 魔素だまり：文章、選択肢（最大4つ）。人が要る選択肢を押すと、パーティから人を選ぶ欄が出る。判定ありは各人の技能 Lv と成功の見込み（％）を出す。戦闘不能は選べない。「決める」で 2d6 を振る。
  - 判定の結果：出目・技能 Lv・合計・難易度・成功／失敗と、受けた効果（淵遺物・アイテム・一時バフ）の札。
  - 宝箱：引いた中身の札（アイテムは受け取る人を選ぶ。戦闘不能も選べる。淵遺物は魔力負荷の増え方と代償）と「見送る」「受け取る」。
  - 町・先人のキャンプ：文章と、パーティの HP・MP の回復（戦闘不能からの復帰の印）。
  - ホロウデータ：イベント・宝箱・ドロップ表のタブと、マップのタブに足すイベントの表・宝箱の表。
- 置き方：A は地図の上に窓として重ねる（地図が後ろに透ける）、B は報酬や虚夢変転と同じく盤面の場所を使う。
- 見せる：魔素だまりの選択肢で、技能・難易度と成功・失敗の効果を全部見せるか、技能と難易度だけか、ラベルだけか。

URL の `?scene=chest-item&place=stage&viewer=player&reveal=check` でも切り替えられる。
