## 正本と版の扱い

基本ルールブックはルールと裁定、セッション操作ガイドはアプリの操作を扱います。アプリの内部操作・実装仕様は`manuals/`のMarkdownが正本です。`manuals/typst/`はその整形版で、このルール本とは別系統です。

個別スキルやアイテムの数値・効果は、アプリの表示とGMの案内を基準に確認します。世界観の入口はユーザー了承済み（一旦）で、現行設定との調整は後で行います。統合したことをもって刊行・全裁定の確定とは扱いません。

## 配布と再生成

配布先・版表示・奥付・改訂履歴は段階6で決めます。リポジトリ直下で実行します。

```powershell
typst compile --root typst_manual typst_manual/全体マニュアル/main.typ typst_manual/全体マニュアル/main.pdf
```

索引56語と第2章から巻末の表への2か所は、同じ文書にリンク先ラベルが1つだけあれば自動でリンクにします。章別レビューでは参照先を含まないので文字だけになります。その他の章をまたぐ参照のリンク化は段階6で扱います。

旧版は保存PDFを上書きせず、確認用の出力先を指定して組版できます。

```powershell
typst compile --root typst_manual typst_manual/全体マニュアル/旧版/旧ルール本.typ typst_manual/_local/work/46_integration/legacy-validation.pdf
```

旧版は本文を保存しているため、この環境では既存の`Noto Serif CJK JP`未導入警告が1件あります。新しい本と章別レビューは警告なしで組版できます。
