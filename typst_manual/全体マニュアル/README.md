## 正本と版の扱い

卓上ルール・世界観は `main.typ` を編集し、`main.pdf` を再生成します。アプリ操作・実装仕様は `manuals/` のMarkdownが正本です。`manuals/typst/` はそれらの整形版であり、このルール本とは別系統です。

個別スキル等の数値・定義は第三章で案内するマスターデータを参照します。シート更新と稼働アプリのキャッシュ反映には差が生じるため、数値や挙動に相違があればGM・管理者へ確認してください。文書再編だけでゲームルールや実装の裁定を変更しません。

## 配布と再生成

PDF内にはGitHub上の読者別入口へのリンクと、リポジトリを手元に置いた場合の参照パスを記載しています。GitHubへのアクセス権と変更の公開反映は別途必要です。公開アクセスは未確認のため、PDF単体を渡す際は、受取人が読める操作マニュアルのURLまたは文書も併せて渡してください。

リポジトリ直下で実行します。

```powershell
typst compile "typst_manual/全体マニュアル/main.typ" "typst_manual/全体マニュアル/main.pdf"
```

再生成後は第三章の案内、リンク、改ページを確認し、編集元とPDFを一緒に管理してください。
