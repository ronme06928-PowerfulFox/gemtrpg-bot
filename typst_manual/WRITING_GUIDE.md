# 書き方の手引き（基本ルールブック・セッション操作ガイド共通）

作成日: 2026-10-17
位置づけ: 公開用の冊子（基本ルールブック、セッション操作ガイド）の原稿を書くときの共通ルール。計画46の段階3「代表章の試作」で、ユーザーの修正と指示から決まった内容をまとめた。新しい章はこの手引きに従って書く。決定の経緯は [計画46](../manuals/planned/46_Manual_Restructuring_Plan.md) の決定事項ログを参照。

この手引きを変えるときは、ユーザーの確認を取り、計画46の決定事項ログにも記録する。

## 1. 文体

- です・ます調で書く。
- 「比べる、反映する、引き継ぐ」のような標語を使わない。見出しには、その節で実際に説明する処理を書く。
- 「マッチ！」「獲得できた！」のような掛け声を加えない。
- 主語や条件を省略した短文を並べない。条件・処理・結果を文章としてつなぐ。
- 作例の前提は「今回は〜ものとします」のように示す。
- 例外は「ただし、シナリオに指定があれば〜」のように具体的に書く。
- 言わなくても分かる補足は書かない。1つの例で伝えることに絞る。

## 2. 用語

| 使う言葉 | 意味・注意 |
| --- | --- |
| 味方陣営・敵陣営 | 決まった呼び方。PL側とエネミー側を指す |
| 同陣営・相手陣営 | 相対的な呼び方。誰の視点かで指す陣営が変わるため、本文では視点が分かるようにする |
| スロット | 1回分の行動枠。行動回数はスロットの数で説明する |
| 解決フェーズ | 宣言をすべて確定した後に、スキルを処理する段階 |
| 使用コスト | スキルを使うときに支払うFP・MP・HP。「使用時の消費」とは書かない |
| 戦闘突入／戦闘終結 | 通常ルームでGMが戦闘の始まりと終わりを区切る操作 |

## 3. 作例キャラクターの名前

- 作例のキャラクター（ナギなど）の名前は、章の冒頭で「例として〜を使います」と紹介するときと、図の中だけで使う。
- 本文では「作成したキャラクター」「自分のキャラクター」「キャラクター」のように抽象化して書く。
- 作例の数値を示すときは「今回は『6』」「今回の結果は9対6で」のように、一般的な手順と今回の例を書き分ける。
- 基本ルールブックと操作ガイドの両方に適用する。

## 4. 改行と余白

- 段落の中の改行と、段落と段落の間の余白を区別する。
- 文中で改行したい箇所は改行し、説明のまとまりが変わる箇所で段落を分ける。段落間の余白は1.4em。

## 5. 図

- 図を中心に構成し、図のそばに短い説明を付ける。
- 同じキャラクター・色・記号・矢印を、章をまたいで使い回す。
- 色だけで意味を表さない。名前・数値・矢印の向きを併用する。
- 1つの図に例外を詰め込まない。比べたいもの（マッチと一方攻撃、防御と回避など）は図を分ける。
- 基本ルールブックはルールを理解するための模式図を使う。
- 操作ガイドも、実画面の写真ではなく、画面の要素を簡略化した図を使う。説明に必要な要素だけを描き、画面に残っていても利用者に表示されない要素（タイムラインなど）は描かない。
- 図にアカウント情報、参加コード、個人的なチャットなどを含めない。

## 6. 表

- 必要な列だけを載せる。結果の表なら、その節で伝えたい項目（例：使用スキル・マッチの結果・受けるダメージ）に絞る。
- 表題は内容を表す言葉にする（例：「この例での結果」ではなく「スキルの種類とマッチの勝敗」）。

## 7. 冊子の分担と参照

- ルールの意味と計算は基本ルールブックで説明する。操作ガイドは画面操作だけを説明し、同じ計算を書かない。
- 冊子をまたぐ参照は「冊子名＋節名」で書く（例：基本ルールブックの「〜」）。ページ番号は補助として扱う。

## 8. 操作ガイドの章の組み立て

- 手順は「前提 → 操作 → 確認できる結果 → 失敗時の確認」の順で書く。
- ボタン名・案内文は実装と照合して書く。
- GMが行う操作は、プレイヤー向けの章では「待つ場面」として書き、手順はGM編で扱う。
- 各章の末尾に、その章の操作で起きることだけを集めた「困ったとき」を置く。巻末には、全章の「困ったとき」を症状から引ける索引を置く。

## 9. 判型

- A4縦の1段組。画面での閲覧と印刷の両方を想定する。

### 段階4Cで採用した紙面設定（2026-10-18）

ユーザー確認により、比較版のC案を当面の設定とします。全編組版・読者確認で調整が必要になった場合は、改めて確認して決定事項ログを更新します。

- フォントはNoto Sans JP、本文11pt。段落間1.4em・行間0.65em。
- 左綴じで、内側24mm・外側20mm・上下23mm。本文幅は166mm。
- 章見出し23pt、節見出し14pt。節見出しの前3.5mm・後1.5mm。
- 節見出し（中見出し）の先頭に直径1.8mmの青い丸を置き、2.2mmの間隔を空けて文字を始めます。文字の開始位置は本文左端から4mm右。折り返しも同じ位置にそろえます。記号は本文の見出しだけに付け、目次・しおりには含めません（2026-10-19ユーザー依頼による追加）。
- 図の前後3mm・枠内上下3mm、図注9pt。図の幅を本文幅へ合わせ、文字全体の縮小で収めません。
- 説明は見出し・本文・必要な図、手順は前提・操作図・結果・注意、参照は項目・条件・処理結果・例外・参照先の順に配置します。本文全体を枠で囲みません。
- 柱で章・節、フッターでページ番号を示します。見開きでも各ページの図と操作が独立して読めるようにします。

実装は `manual_theme.typ` の `publication-conf` と `publication-figure` を使用します。基本本の既存原稿内の重複設定は段階5で移行し、操作ガイドの新規原稿にはこのテーマを適用します。
