> 2026-10-17：以下と「文体の調整」の内容は、決定済みの方針として[書き方の手引き](../WRITING_GUIDE.md)にまとめた。新しい章は手引きを正とする。

- 段落内の改行と段落間の余白を区別する。2026-09-20のユーザー指定により、防御・回避の試作では本文の段落間隔を1.4emに調整した。文中の改行は維持し、説明のまとまりが変わる箇所に余白を設ける。

- 初心者向け本文は図を中心に、図のそばに短い説明を付ける。同じキャラクター・色・記号を繰り返し使う。
- マッチ／一方攻撃、対象変更、防御／回避、複数行動、広域はそれぞれ図で比較する。一つの図に例外を詰め込まない。

- 基本本はルールを理解する模式図、操作ガイドは実画面の操作箇所を示す図を使う（2026-10-17決定で、操作ガイドも写真ではなく簡略図に変更）。

## 検証

### 文体の調整（2026-09-18）

図解初稿の文章について、ユーザーから「AIっぽ過ぎる」と指摘があったため改稿した。文体の主な参照先は、ユーザーが修正した[キャラクター作成草案](../../manuals/planned/46_Character_Creation_Walkthrough_Draft.md)の§4・§6。草案全体をユーザー単独の執筆とは扱わず、修正後に採用された文章として参照する。既存基本本の探索判定なども確認したが、個々の文の執筆者は未確認。

- 「比べる、反映する、引き継ぐ」のような標語を避け、見出しには実際に説明する処理を書く。
- 「マッチ！」「獲得できた！」のような掛け声を加えない。
- 説明文はです・ます調とし、主語や条件を省略して短文を並べない。図中の数値ラベルは短く保つ。
- 「今回は〜ものとします」で作例の前提を示し、条件・処理・結果を文章としてつなぐ。
- 例外は「ただし、シナリオに指定があれば〜」のように具体的に書く。

この方針は今回の修正案であり、本人の文体を確定的に定義したものではない。図の配置と作例の数値は維持し、PDFを再生成して両ページの表示を確認した。

続くユーザーの直接修正を図解へ反映した。見出しは「戦闘の流れ」、冒頭は「作成したキャラクターを使って、戦闘の開始から1ラウンドが終わるまでを見ていきます。」とする。行動回数をスロット数で説明し、図中の呼称も「スロット」に統一。「全員の宣言が確定したら、解決フェーズに移行します。」「味方と敵の宣言を確定すると、解決フェーズでスキルの処理を行います。」を採用した。これらは執筆者を推測した参考文ではなく、ユーザーから指定された表現として今後の文体調整でも参照する。

PDFは2ページ。両ページをPNGへ描画して表示確認。数字は元草案の開始値・終了値と照合した。前段階での実装照合と74テストの記録は本文草案に保持している。今回は図解のみの変更のため戦闘テストは再実行していない。

本例のブラウザでの通し再現、実画面との並列ユーザーテスト、基本本全体の組版は未実施。今回の2ページには書籍全体の前後関係・参照ページ番号をまだ付けていない。
