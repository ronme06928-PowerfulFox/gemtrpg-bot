# 本編カットの進行

`prepare-round-v2.mjs` が生成する本編専用。JSONはカットの `id` と段階表示の `phase`。
各共通部品を `steps="0"` にし、この要素をsectionの末尾へ置く。egatari v0.4.5のDOM順の描画で、共通部品の初期描画後に `render(k,t)` を呼び直す。補間は共通部品へ委ね、数値・表示・強調を毎回復元する。

`DECK.AUDIO` のcueから語の開始と結果の時刻を求める。速度・味方威力の開始は下記の同期改訂に従い、敵威力はC07段階1の開始から、一撃は命中の0.8秒前から動かす。ダイスの確定音は出目停止時刻へ混ぜる。4段階の名前はC02の4つの `{cue}` で0.65秒ずつ縁取り、現在段階の塗りを動かさない。C05はGM出現後0.6〜1.2秒に6を光らせ、その後解決へ入る。

注意：親子の部品の描画順を逆にすると、子の段階0が最終状態を上書きする。部品の自律進行と混ぜない。元の声がない段階やcueの欠損は生成・検証側で失敗させ、無音で埋めない。

途中状態の検査で、速度の点灯を両スロットへ適用する誤りを検出し、味方6だけに限定した。行動済みのラベルに親のopacityを掛けない。FPの理由札は幅150pxで折り返さず、敵側は本文右端1236pxより内側へ置く。

使い方は本編の生成HTML。途中・最終・巻き戻しは `verify-round-v2.mjs` で確認する。

冒頭カットのmount時にdeck:readyを一度だけ待ち、DECK.captions(true)でHTMLの字幕を初期表示する。Sキーによる切替はegatariの標準操作を使い、場面移動で字幕を再強制しない。

SEの対応：C02は開始0秒、C04のスキル札は段階2の開始0秒、段階4のマッチ矢印は確定cueの0.5秒前、C11の空スロットとGMは0.5秒。説明の次の段階へ進んでもGMを再出現させない。変化のないC03スロット紹介に旧SEを残さない。

同期改訂：JSONにwordLead（partGap＋prePhonemeLength、現設定0.22秒）を渡す。C01[3]の2cue、C03[1]の2cue、C06[2]の4cueで語の開始を求める。C03はcue 0の語から振り、敵は0.4秒後。1.1秒で出目停止・式の行を表示、2.4秒でスロットへ入る。C06は4項目の最後のcueで転がし始め、それまでは4＋1d2＋1d3を表示する。強調は毎回リセット。以前の結果の文末からの逆算は使わない。

C07は段階1（語りなし・2.6秒）で振り、1.1秒で出目停止、2.4秒で式へ入る。段階2は開始時から1と1と＝6を保ち、文末のpower-enemyのcueで比較札を出す。C04のマッチ矢印の印はcircleを使い、spotの白い覆いを出さない。

文単位の字幕に合わせて、C01は段階1の紹介文までタイトルを保つ。C02段階2でスロットの丸を説明する。C05の速度6の点灯は段階1だけ。C09段階2でタイミングを囲み、C10段階1で効果全体へ広げ、段階2ではInfinityを渡して幅を保つ。文を進めるたびに拡張をやり直さない。
