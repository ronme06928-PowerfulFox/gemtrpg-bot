# UIデザイン決定ログ

最終更新: 2026-08-07

## 1. 目的

画面ごとに「どのような見た目にしたか」「なぜその表現を選んだか」「他画面でも再利用できるか」を記録し、アプリ全体のUIデザインの統一感を段階的に高めるための継続更新用覚書である。

この文書は実装済み画面の観察記録と判断理由を扱う。未実装案は`manuals/planned/`、正式なUI仕様は`manuals/implemented/E01_Visual_Battle_Architecture.md`と`manuals/implemented/E02_UI_Component_Specs.md`、実際の色・寸法・挙動はソースコードを正とする。

## 2. 更新ルール

1. 新しい画面の実装または大きなUI調整が完了した時点で、コミット前に1画面単位の記録を追加する。
2. 提案段階の内容を完成済みとして記録しない。計画中は登録予定だけを示し、実画面確認後に内容を確定する。
3. 色の名称だけでなく、CSS変数、主要クラス、適用範囲を記録する。
4. 同じパターンを別画面でも再利用できる場合は「共通化候補」と記載する。共通ルールとして採用したらE02と`static/css/modules/common_ui.css`へ反映する。
5. 既存の共通ルールから意図的に外れる場合は、理由と適用範囲を「例外」として記録する。
6. 一時フォルダの画像を参照しない。比較画像を保存する場合はリポジトリ内の永続パスへ置く。
7. デザイン変更時は既存項目を無言で置き換えず、更新日と変更理由を追記する。

## 4. 2026-08-07: プリセット管理・配置UI

- 状態: 実装済み。実ブラウザーでの最終目視確認は手動確認事項として継続する。
- 関連計画・仕様: 計画44、`implemented/D01_Play_Mode_Specs.md` Part 5、`implemented/E02_UI_Component_Specs.md` Part 11
- 対象画面・入口: 通常ルームのフィールド、戦闘専用詳細調整、プリセット管理ワークスペース
- 主目的: 永続資産の管理と、セッション中の一時的な配置操作を混同させず、大量のプリセットから短い操作で必要な構成を呼び出す。

### レイアウトと情報階層

- 配置画面は分類、候補一覧、今回の配置の3領域とした。基準幅は280px、最低520px、360〜420pxで、選択の中心である候補一覧へ最も可変幅を与えた。
- 管理画面から旧「戦闘準備」タブを外し、ヘッダーの「ルームへ配置」で独立画面へ遷移する。編集フォーム、管理、配置、戦闘詳細を可視状態で重ねない。
- 配置トレイはステージ・各陣営編成を1件、単体キャラクターを複数件保持し、変更予定を下部に常時表示する。確定操作はサーバープレビュー成功後だけ有効にした。
- コレクションは専用検索、件数、選択時の区分ツリーを持つ。行内の星と省略操作へ補助操作を集約し、長い常設ボタンで名称領域を圧迫しない。
- 一覧カードは件数が少ない場合も残りの縦幅へ伸長させず、内容高のまま上へ詰める。
- 長いコレクション名・区分名のためにサイドバー幅は広げず、省略表示と全文ツールチップを併用する。
- スクロールは各ペイン内に閉じ、ヘッダー、一覧ツール、配置トレイ見出しには不透明背景を与えた。

### 配色と状態表現

- 配置画面は既存の`--bo-*`系トークンを優先し、淡い緑系の面、白いカード、濃緑の主操作を使った。危険操作は既存の赤、警告は黄土、阻害事項は赤文字と枠付きメッセージを使う。
- ステージ、味方編成、敵編成、キャラクターは文字ラベルを必ず表示する。選択、準備完了、警告、無効は色だけに依存せず、文言、枠線、ボタンの有効状態を併用する。
- ブックマークは星を用いるが、`title`と`aria-label`で追加・解除を明示する。アーカイブは「非表示中も表示」「普段の一覧から隠す」と言い換え、削除との違いを説明する。

### レスポンシブとアクセシビリティ

- 1180px以下では配置トレイを右ドロワーにし、「今回の配置 (N)」から開閉する。760px以下では分類も左ドロワーにして候補一覧を主領域に保つ。
- ドロワーボタンは`aria-controls`と`aria-expanded`を持ち、状態メッセージは`role="status"`で通知する。
- `prefers-reduced-motion`ではトランジション時間を実質ゼロへ抑える。狭幅でも横スクロールを前提にしない。

### 共通化候補・例外

- 共通化済み: `PresetDeploymentBrowser`を通常ルームと戦闘専用で共有し、配置先だけ`targetMode`で切り替える。
- 共通化候補: 件数付き分類ツリー、右側インスペクター、サーバープレビュー後に主操作を解禁するパターンは、今後の大規模カタログ画面でも再利用できる。
- 例外: 配置トレイの緑系表現はセッション準備の文脈を示すための画面限定テーマであり、現時点ではアプリ全体の色規則へ昇格させない。
