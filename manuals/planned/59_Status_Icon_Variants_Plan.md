# 計画59：状態アイコンの描き分け

作成日: 2026-11-03
状態: たたき台（議論前）。計画57 §9-10（累積状態の常時表示）の実装で出た課題を、計画57の画像（論点8、保留中）から切り出した。

## 1. 目的

状態のアイコンが、意味の違う状態どうしで共通になっている所を、別のアイコンで見分けられるようにする。

- 凝魔-血漿（Bu-48）は凝魔、蓄力-誘爆（Bu-49）は蓄力と同じアイコンを使っている。今は解決パネルの累積状態の表示で、縁の色（血漿 `#ff4d6d`・誘爆 `#ffd43b`、3px）だけで見分けている（計画57 §9-10）。
- 荊棘重絡も、荊棘と同じ `thorns.png` を使っている（`STATUS_CONFIG` の色だけが違う）。

## 2. 今の作り（2026-11-03 調査）

- アイコンは `static/images/` の7枚（`bleed` `rupture` `fissure` `fear` `thorns` `gyoma` `chikuryoku`）。状態とアイコンの対応は `static/js/battle/utils/Constants.js` の `STATUS_CONFIG`（状態名がキー）。
- アイコンを使う所：
  - 盤面の駒の状態バッジ・対決画面のアイコン（`static/js/visual/visual_map.js`）
  - 状態の一覧のモーダル（`static/js/modals.js`）
  - 解決パネルの効果の帯（`resolve_flow_fx.js`。付与の記録の `status` を鍵にする）
  - 解決パネルの累積状態の表示（`resolve_stacks.js`。変換後は記録の `name` で縁の色を変える）
  - 演出の一覧・解決パネルの見本（`scripts/fx_gallery/embed_icons.py` が7枚を埋め込む）
- 変換後の名前（凝魔-血漿・蓄力-誘爆）は、サーバーの記録の `name` に入る（B03）。`status` は元の状態のまま。盤面の駒の状態バッジは、変換後を見分けていない。

## 3. 論点（議論前）

1. **対象**：凝魔-血漿・蓄力-誘爆だけか、荊棘重絡も含めるか。今後増える変換後の状態（B02 の「特殊蓄力variant追加時のaliasポリシー」）をどう扱うか。
2. **見分け方**：まったく別のアイコンにするか、元のアイコンに印（しずく・火花など）を重ねるか。後者なら、印だけを1枚作って重ねる形もある。
3. **作り方と記録**：誰が・何で描くか（手描き、画像生成など）。出どころ・作り方・ライセンス・作者・加工の有無の記録（計画57 §6 と同じ決まり）。置き場所（リポジトリの `static/images/`）。
4. **使う所の範囲**：解決パネル（効果の帯・累積状態）だけか、盤面の駒の状態バッジ・状態の一覧のモーダルまで広げるか。盤面まで広げるなら、盤面で変換後をどう知るか（キャラの `special_buffs` の variant）。
5. **鍵の持ち方**：`STATUS_CONFIG` に変換後の表示名のキーを足すか、`status` と variant から引く別の表にするか。縁の色（計画57 §9-10）は残すか、やめるか。

## 4. 関係

- 計画57：§9-8（画像の使いどころ）とPR57-3は保留中。アイコンの問題だけを、この計画で先に扱えるようにした。計画57の画像を再開するときは、この計画の結果に合わせる。
- 仕様：累積状態の表示はE02 Part 14、記録はB03。
