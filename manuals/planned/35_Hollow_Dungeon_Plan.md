## 1. 目的

- GM の重い準備なしで繰り返し遊べる戦闘コンテンツ（ハクスラ）を作る。GM がいなくてもプレイヤーだけで遊べる。
- 「階を降りるほど敵が強くなる／手に入れたもので自分も強くなる」を、今ある戦闘処理・ユニット・マスターデータの組み合わせで作る。新しい戦闘処理は作らない。
- シナリオで育てた持ちキャラを連れて行く先にする。

## 2. 対象範囲

### 扱うもの

- 浅層 1F〜50F の階層進行（ラン開始〜クリア・全滅・撤退）。10F ごとの地図で、次のマスを選んで1F ずつ下る（§4.9）。
- マスの種類の抽選（通常戦闘・精鋭戦闘・宝箱・魔素だまり）と、固定階（ボス・町・先人のキャンプ）。
- 階に応じた敵の編成と強さの補正。
- 報酬（アイテム・淵遺物）と、戦闘をまたいで続く一時バフ。
- ホロウデータの画面（敵・編成・ステージと、ホロウだけのデータ）。
- メインメニューの「ダンジョン」の札から入るホロウの部屋。パーティ編成とホスト（進行役）。
- ラン状態の保存（中断・再開）と、持ちキャラへの経験値の反映。

## 4. ゲームデザイン（2026-07 に決めたもの。改訂でも変えない）

### 4.1 世界観

- ホロウは、600年前の噴火と大宝石の加護で島ひとつが吹き飛んだ跡にできた、魔力が濃すぎる巨大な穴。内部は地上の常識が通じない。
- ホロウで死んだ探索者が自覚なく彷徨う亡霊、探索者の記憶を読んで作られた写し、という不穏さが軸。
- 浅い階は「変異したシュラーカーを狩る」感覚、深い階は「濃すぎる魔力そのもの＝異形と戦う」感覚へ移っていく。

### 4.2 階層とビジュアル

| Tier | 階 | 難しさ | 見た目 | 敵の基本の等級 |
|---|---|---|---|---|
| T1 入穴 | 1〜10F | 地上の危険地帯並み | 荒野・洞窟。まだ地上の延長 | 鉄級 |
| T2 浅層上部 | 11〜20F | T1の1.3〜1.5倍 | 異常な宝石が見え始める | 銅級 |
| T3 浅層中部 | 21〜30F | 精鋭が増える | マグマ地帯と寒冷地帯が隣り合う | 銀級 |
| T4 浅層下部 | 31〜40F | 魔素だまりが増える | 鉱脈と樹木が混ざった「森」（地下にあるはずのない生態系） | 金級 |
| T5 深層境界 | 41〜50F | ステージ効果が常にかかる階が混ざる | 魔力生物化。獣の面影が消えていく | 特異級 |

- 固定階：10F・20F・30F はボス＋町（全回復・次のマップを選ぶ。中断・再開の目印）。40F はボス＋先人のキャンプ（部分回復・次のマップを選ぶ）、45F は先人のキャンプ（部分回復）、50F は最深部のボス（撃破でクリア）。ボスは区切りのマップが持つ（§4.9）。範囲は浅層の 50F まで（深層 51F〜は別の計画）。
- Tier は10F の区切りそのもの（T1＝1〜10F … T5＝41〜50F）。区切りの最後の階がボス。Tier は区切りの番号（1〜5）で持ち、階の範囲は持たない（決定 → §9）。
- 固定階以外のマスの種類は、地図を作るときに 選んだマップの重みで抽選する（§4.9）。

### 4.3 敵（シュラーカー）

- 既存設定のシュラーカー（鉱石を核に魔力を吸って育つ魔法生物、体色＝金属等級）をそのまま使う。
- 等級（鉄・銅・銀・金・特異）は Tier とゆるく対応させる。雑魚・中堅はその Tier の等級、精鋭は1つ上の等級。低い階でもまれに上位の等級が出る。
- 名前は既存の決まり「[地形]の[等級]級シュラーカー」。地形は §4.2 の見た目に合わせる。
- 等級はキャラクタータグ（「鉄級」「銅級」「銀級」「金級」「特異級」の5つ）で持つ（決定 → §9）。ホロウの敵ユニットには等級タグを1つ付ける（保存前チェックで確かめる）。淵遺物の条件（`has_tag`）や行動チャートの条件で使える。
- 見た目は動物のシルエットに核の鉱物の質感が覗く程度。等級が上がるほど鉱物的な逸脱が強くなり、特異級では動物の輪郭が失われる。個体の名前とデザインはデータ作成時に決める。
- 各敵にアイコン画像を持たせる（ユニットの `image`）。

### 4.4 階のイベント

- 通常戦闘（いちばん多い）／精鋭戦闘（強い・報酬がよい）／宝箱（戦闘なしでドロップ）／魔素だまり。
- **魔素だまり**は旧「残留思念」を含む。環境の澱み・思念との対話・尋問を文章で描き分け、解決の仕組みは共通にする。
  - 選択肢は最大4つ。各選択肢は「判定あり」か「判定なし」。
  - 判定ありは、ホストがパーティから1人を選び、その1人が探索判定に挑む。成功で効果（小アイテム・一時バフ）、失敗で状態異常・一時デバフ。失敗の影響が「選んだ1人」か「パーティ全体」かは選択肢ごとに決める。
  - 判定ありの選択肢は、技能（探索技能12種：五感・採取・本能・鑑定・対話・尋問・諜報・窃取・隠密・運動・制作・回避から1つ）と難易度を持つ。判定は今の探索判定と同じ 2d6＋その技能の Lv で、難易度以上なら成功。
  - 判定なしは確定の効果。「やり過ごす」は効果なし（ノーリスク・ノーリターン）。
  - 効果は、一時バフ（あと何回の戦闘かを必ず持つ）・アイテム・淵遺物（出身強化を手に入れる道。手に入れたときの魔力負荷を積む）のどれか1つ。成功の効果の対象も「選んだ1人」か「パーティ全体」を選択肢ごとに決める。アイテムは選んだ1人が受け取る。判定なしでも、選んだ1人が要る選択肢ではホストが1人を選ぶ。
- **ベースキャンプ**はマスとして置かない。設定では1〜30F の各階にベースキャンプがあるので、1〜30F では1階降りるごとにパーティの最大 HP の10%と最大 MP の20%を回復する（31F 以降は回復しない）。戦闘不能のキャラは起き上がらず、町か先人のキャンプでだけ回復する。
- **宝箱**は選択肢なしで、宝箱のドロップ表から1つ引く。アイテムならホストが受け取るキャラを選ぶ。淵遺物なら戦闘の報酬と同じく魔力負荷を積む（所持済みは汎用素材）。受け取るか見送るかはホストが決める。
- どの魔素だまり・宝箱が出るかは、マップの重みつきの表（イベントの表・宝箱の表）から、マスに入ったときに引く（遭遇表と同じ）。
- **町**（10・20・30F のボスの後）は全回復（HP・MP。戦闘不能も起き上がる）。**先人のキャンプ**（40F のボスの後・45F のマス）は最大 HP・MP の50%を回復し、戦闘不能のキャラは最大 HP の50%で起き上がる。値は段階8で直す。
- T4 以降の一部の階は、イベントとは別に、階全体にステージの効果がかかる。仕組みは T4 のデータを作るとき（段階7〜8）に決める。

### 4.5 報酬・淵遺物・一時バフ

- **ホロウ内で完結**：アイテムも淵遺物もラン終了（クリア・撤退・全滅）で消える。持ちキャラに反映するのは経験値だけ。
- **経験値**：階を1つ進むたびに少しずつ、ボス（10F・20F・30F・40F・50F）を倒したときはより多く、そのときパーティにいる持ちキャラに積まれる。ラン終了（クリア・撤退・全滅）のときに自動で持ちキャラへ反映する（決定 → §9）。1階・ボスごとの点数と、浅い階の周回で稼ぎ過ぎないための1ランの上限が要るかは、セッションでの成長との釣り合いを見て段階7で決める。今の「成果を反映」はルームのキャラクターごとに1回だけの印を持つので、ホロウではラン単位で反映する形に作る。
- **淵遺物**：ホロウの濃い魔素が、落ちていた道具・魔導具・聖遺物に染みついて生まれたもの。残留思念が道具の形になったものもある。
  - **カテゴリとランク**：淵遺物は12のカテゴリ（出血・破裂・亀裂・戦慄・荊棘・蓄力・凝魔・斬撃・打撃・貫通・汎用・出身強化）のどれか1つに属し、ランクⅠ〜Ⅴを持つ。ランクが上がるほど強く、特殊な効果が出る（宝石の加護の魔法をまねた効果もよい）。レアリティ（等級の5段階）は持たない。
  - **魔力負荷**：パーティは1つの魔力負荷を持つ。淵遺物を戦闘のドロップなどで手に入れるたびにそのランクの数字を足し、降りた階の分も足す。手放しても合成で材料を消しても減らず、虚夢変転でできた遺物を手に入れても足さない。階は1つ降りるごとに、1〜10F なら1ずつ、11〜20F なら2ずつ、21〜30F なら3ずつ（区切りの番号ずつ）増える。魔力負荷は減らせない（淵遺物を捨てる・浄化する手段は作らない）。
  - 淵遺物の魔力負荷はランクの数字と同じ（Ⅰは1、Ⅴは5）。遺物ごとの上書きはしない。
  - **ドロップのランク**：出るランクの上限は、通常戦闘は Tier の番号まで、精鋭戦闘は1つ上、ボスは2つ上（最大Ⅴ）。上限の重みは1、1つ下は2、それより下は各1。マップのカテゴリの重みを使い、最大3つの候補を引く。選択・見送りを確定すると、次のマス、虚夢変転、次のマップ、クリアのいずれかに進める。
  - **虚夢変転（合成）**：各区切りの (10N＋9)F を終えた後、ボスの階へ降りる前に、マスとは別の「合成のフェーズ」を挟む（9F・19F・29F・39F・49F の後）。淵遺物を最大4つ合成して別の淵遺物を1つ作る。できるランクは、材料のランクの合計を一定の数で割ったもの。カテゴリは引く。**祈念**を使うとカテゴリを選べ、合成のフェーズごとに決まった回数だけ使える。特定の組み合わせの材料からは、特別に強い淵遺物ができる。合成にコストはない（手に入れたときの魔力負荷がコストの代わり）。町やキャンプでは合成しない。材料は2〜4個で、合成のフェーズの中なら何回でも合成できる。できるランクは材料のランクの合計÷2の切り上げ（Ⅰ〜Ⅴに収める）。祈念を使わないときのカテゴリは、材料のカテゴリから数の多いものほど出やすく引く。祈念は出身強化を除く11のカテゴリから選べ、合成のフェーズごとに1回。**特別な組み合わせ**は、材料を淵遺物の ID の組（2〜4個）で指定し、当てはまれば普通の計算と抽選の代わりに決められた淵遺物が1つできる（祈念は使わない）。組み合わせは見つけるまで隠し、当てはまる材料を選んだときに「特別な遺物ができる」と予告する。一度作った組み合わせは、そのアカウントの一覧に残る。
  - **出身強化**：特別なカテゴリ。戦闘の報酬・合成の抽選・祈念では出ず、イベントか特別な組み合わせの合成でだけ手に入る。マップのカテゴリの出やすさにも持たない。
  - **代償の段階**：魔力負荷が区切りの値に達するごとに段階が上がり、その段階の代償のバフがパーティ全員に積み重なる（例：段階1で発熱、段階2で獣性の異常発達、段階3で錯乱）。区切りと代償はホロウデータの「魔力負荷の段階」で編集する。戦闘の始めに、その時点の段階の代償を付け直す。
  - **個別の代償**：特に強い一部の淵遺物は、代償のバフを1つ持てる（空でもよい）。恩恵と同じ対象に、持っている間ずっと付く。代償つきの遺物には、ドロップや窓で「代償」の札を出す。
  - 効果は既定でパーティ全員。条件（HP が最も低い・前のラウンドで出血・タグ）か、パーティの並び順（N番目）で絞れる。条件の最初の3種類は `hp_lowest`・`bled_last_round`・`has_tag:<tag>`。
  - 効果はバフ（マスターデータのバフかホロウのバフ）で表す。淵遺物1つにホロウのバフを1つ付け、バフの名前は遺物と同じにする（同じ名前のバフは上書きされるので、遺物ごとに一意）。
  - **バフのタイミングつきの効果**（PR35-12）：バフはスキルと同じタイミング（スキル使用時・的中時・マッチ勝利時・マッチ敗北時・一方攻撃時・マッチ終了時・ラウンド開始時・ラウンド終了時・戦闘突入時）と新しい「相手を戦闘不能にしたとき」に、スキルと同じ効果（状態の付与、スタックの獲得と消費、出血氾濫などの効果、HP の回復、FP・MP の獲得）を、バフの持ち主について動かせる。バフの条件は、スキルの属性（斬撃・打撃・貫通）と分類（物理・魔法）も見られる。通常ルームのバフにも使える。書式は `effect.effects`、開始は `START_ROUND`、撃破は `ON_KILL` とする。
  - **汎用素材**：すでに持っている淵遺物をもう一度手に入れると、代わりに同じランクの汎用素材が1つ手に入る（同じ名前のバフは重ならないため）。汎用素材は効果を持たず、合成の材料にだけ使える。手に入れたときにランクの数字を魔力負荷に足す。合成ではランクの計算にだけ入り、カテゴリの抽選には数えない（材料が素材だけなら、出身強化を除く11カテゴリから等しく引く）。
- **一時バフ**：「あと何回の戦闘のあいだ続くか」を持てる。戦闘が1回終わるたびに1減り、0で消える。戦闘のたびに、そのバフの持続ラウンドぶん付け直す。

### 4.6 心身異常（魔素の影響）

- 身体系：「獣性の異常発達」は、物理・魔法補正や威力が上がる代わりに、毎ラウンド速度が落ちスキルのコストが上がる諸刃の効果。「発熱」は HP が減る効果。
- 精神系：錯乱・発狂・恐慌。今ある状態異常を使う。

### 4.7 全滅・撤退・再開

- 全滅でラン終了。再挑戦は常に 1F から（新しい部屋で）。
- 撤退は戦闘中でないときだけ選べる。安全にランを終えるだけで、持ち帰りはない。
- ラン中に中断しても、ラン状態は部屋に保存され、次の回に同じマスから再開できる。
- **部屋は1回の遠征（ラン）のためのもの**（決定 → §9）。部屋を作る → パーティを組む → ラン → 終了（クリア・撤退・全滅）で結果を出し、部屋を閉じる。閉じた部屋はダンジョンの画面の一覧から消え、入れない。中にいる人が結果を見て出たら消す（消す時機の細部は PR35-8 で決める）。次も同じ仲間で遊ぶときは、部屋を作り直して参加コードを配る。
- 到達階は部屋に記録しない。持ちキャラごとの記録（「このキャラの最深 23F」）にするかは、経験値の反映（PR35-17）と一緒に段階7で決める。

### 4.8 パーティとホスト

- 1つの部屋で1回のランだけ（§4.7）。
- パーティは参加者が自分の持ちキャラから加え、並び順を持つ（淵遺物の「N番目」の基準）。ラン開始時の並びをランの間は固定する。**出撃は4人まで、控えは2人まで、合計6人まで**（並びの1〜4番目が出撃、5・6番目が控え）。内訳（6人の顔ぶれ）はラン開始時にすべて決める（決定 → §9）。控えは戦闘に出ない（盤面に置かれていない味方として扱う）。
- **控えの入れ替わり**：出撃のキャラが戦闘不能になったら、次のラウンドの始めに、控えのキャラが倒れたキャラのいた位置に置かれて戦闘に入る（控えの並びの順）。全滅は、出撃も控えも戦えるキャラがいなくなったとき（決定 → §9）。
- **戦闘不能のキャラ**：戦闘の後は控えに回り、HP が戻るまで出撃できない。キャンプか町で回復したら、ホストが地図の画面（戦闘の外）で出撃と控えを入れ替えられる。顔ぶれはランの間変えられない。
- **控えの人数の補正**：控えを入れると、すべての敵の HP の倍率が上がる。5人目から1人につき＋15%（5人で×1.15、6人で×1.30）。Tier の HP の係数に掛ける。値は段階8で直す。
- **淵遺物と控え**：「全員」は控えも含む。「N番目」はラン開始時の並びの1〜6番目で数え、入れ替わりがあっても持ち主は変わらない。ラン前は、誰でも自分の持ちキャラをパーティに加えられる。外す・並べ替えるのはホストとオーナーだけ（決定 → §9）。プレイヤーは自分のキャラのアイテム使用と、全員の詳細を見られる。
- **ホスト**（進行役）は部屋ごとに1人。既定は部屋のオーナー。ホストが部屋を退出したら、参加した順で次の人に移る（ブラウザーを閉じただけでは移らない）。ホスト本人とオーナーだけが別の人に譲れる。オーナーはいつでもホストの操作を代わりにできる。ホロウの部屋には GM の役割がない（§5.3）。
- ほかの人は、次のマス・撤退などの選択肢に**推薦ピン**を立てて意見を示せる（決めるのはホスト）。初めは次のマスと撤退に絞る。
- 味方キャラは持ちキャラから部屋へ追加する。

### 4.9 地図（マスを選んで下る）

2026-11-26 に、「降りるたびに種類を引く」から「地図でマスを選ぶ」に改めた（決定 → §9）。

- 1つの Tier（10F の区切り）を1枚の地図にする。上から下へ1段＝1F の帯に、マス（アイコンと種類名の札）を並べ、隣の段のマスとまっすぐな道でつなぐ。段の間は道が急にならない広さを取る。
- **スタートマス**：各区切りの地図の一番上に、無地のスタートマスを1つ置く（T1 は「0F 地上」、T2 は「10F」、T3 は「20F」…。T2 以降は前の区切りのボスの階で、倒したボスのマスと同じ札を出す。今いる間は現在地の印、離れたら通過済みの暗い札になる）。ランの開始やボスの後は、ここに「いる」ところから始まり、下の段へ分かれて進む（決定 → §9）。
- **見える範囲**：今いる階の2段下までを見せ、その先は「未踏」の段として階の番号だけを出す。1つ進むたびに1段開ける。サーバーは参加者へ見える段だけを送る（決定 → §9）。未踏の段は、段階7で霧のかかった見た目にする。
- マスの種類はアイコンで分かる：通常戦闘・精鋭戦闘・宝箱・魔素だまり・ボス・先人のキャンプ（45F）。町と 40F の先人のキャンプはボスのマスの後に続く。戦闘マスで分かるのは通常か精鋭かまで。敵の編成はマスに入ったときに遭遇表から引く（決定 → §9）。
- 地図は区切りに入るときに乱数で作る。乱数の種をラン状態に保存し、読み直しても同じ地図になる。固定階（§4.2）はその段にマスが1つだけの段になる。ほかのマスの種類は選んだマップのイベントの重みで引く。
- 今いるマスから道でつながる次の段のマスを、ホストが選ぶ（ほかの人は推薦ピン）。1マス進むと1F 下る。
- 区切りの最後のボスを倒すと町（または先人のキャンプ）を経て、画面が次の区切りの地図に切り替わり、また一番上から進む。
- **マップ**：1つの Tier に複数のマップ（その10F の場所。例：結晶の森、溶岩の回廊）を持てる。マップは1つの Tier 専用で、イベントの重み・遭遇表・淵遺物のカテゴリの出やすさ・区切りの最後のボスを持つ。地図の形（マスの並びと道）は今どおり種から自動で作る。ランの始めと各ボスの後に、その Tier のマップからランダムに3つ（無ければあるだけ）出し、ホストが1つ選ぶ。遊ぶ画面での「Tier」の呼び方は、後で見直す。
- **マップを選ぶ画面**：盤面の場所に、候補のマップを札で横に並べる（3つまで）。札は大きな絵（マップごとに用意する）、名前、説明、出やすい淵遺物のカテゴリを出す。出る敵と区切りの主は見せない。ホストが札を押すと「このマップへ進む」の確認の窓が出て、進むと降下の幕を挟んで地図の画面へ移る。プレイヤーは見るだけ。形は試作 `scripts/hollow_map_select_proto/`（決定 → §9）。
- **地図の揺らぎ**：1段のマスの数は段ごとに抽選し、ほとんどを2〜3にする（1はまれ。固定階は1）。札の左右の位置も少しずらす。道は左端どうしから右端どうしまで交差しない形で抽選し、別れ道・合流と、「こちらに進むとあちらに行けない」道を作る。区切りの最後のボスで必ず合流する。割合はまずコードの値で、Tier ごとに変えたくなったら Tier の項目に足す（決定 → §9）。
- **マスの選び方**：マスにカーソルを合わせると、カーソルに「4F 精鋭戦闘」の札が付く。ホストが選べるマスを押すと「4F 精鋭戦闘」と「入場」「キャンセル」の窓が出て、入場で進む（決定 → §9）。
- **戦闘の配置**：出撃の味方と敵を、盤面の縦の真ん中にそろえて1マスおきに縦へ並べる（駒の上の速度の札と下の名前の札が隣の駒にかからない）。味方は幅の半分から4マス左の列、敵はそれと左右対称の列に置き、入りきらない人数は2マス外側の列へ続ける（決定 → §9）。陣形（前列・後列）や戦闘前に動かせるようにするかは、段階7（PR35-19）で見比べる。
- **画面の切り替え**：マスを選ぶ「地図の画面」と、戦闘の盤面の「戦闘の画面」を、盤面の場所ではっきり切り替える。入場すると地図が上へ沈み、「4F 精鋭戦闘」の幕を挟んで戦闘の画面へ。勝つと「4F 制圧」、ボスの後は「T2 浅層上部」の幕で地図へ戻る（決定 → §9）。形は試作 `scripts/hollow_map_proto/`。
- **パーティの窓**：左のアクションドックの「パーティ」のアイコンから開く窓に、パーティ（並び・HP・MP・FP・アイテム・詳細）と参加者（ホスト・オーナー・譲る）を出す（PR35-6、決定 → §9）。右の列には、ランの状態・ホスト・パーティの人数の細い帯だけを出す。淵遺物の所持と一時バフは、この窓ではなく、段階5（PR35-14）で作る淵遺物の窓に出す。
- **パーティメンバーの追加**：ホロウの部屋では、ドックの「キャラクター追加」を「パーティメンバーを追加」の窓にする。自分の持ちキャラの一覧から選び（複数可、空きの数まで）、部屋に出すと同時にパーティの最後に加える。通常ルームの「味方を追加／敵を追加」と JSON の貼り付けは出さない。ラン前なら誰でも使え、ラン中は押せない。外したキャラは部屋からも消す（ホロウの部屋の味方はパーティだけ）。形は試作 `scripts/hollow_map_select_proto/`（PR35-11、決定 → §9）。
- **淵遺物の窓**：ドックに淵遺物だけの窓を開くアイコンを置く（パーティの窓には入れない）。窓の上に魔力負荷（今の値・段階・次の区切り）、その下に持っている淵遺物をアイコンの格子で並べ、汎用素材の数と一時バフも出す。アイコンを押すと、効果の文・カテゴリ・ランク・対象・個別の代償・フレーバーが出る。アイコンの絵は淵遺物の `image`、無ければカテゴリの色の丸とランク（Ⅰ〜Ⅴ）で出す（PR35-14、決定 → §9）。窓の大きさは中身の長さで変えず（幅920・高さ680を上限に画面へ収める）、一覧と詳しい中身はそれぞれの欄の中で送る。詳しい中身は一覧の右に並べる。
- **戦闘の報酬と虚夢変転の画面**：どちらも盤面の場所に出す（マップを選ぶ画面と同じ置き方）。報酬は候補3つの札（大きなアイコン・名前・カテゴリ・ランク・効果・代償・魔力負荷の増え方、所持済みは「素材になる」の印）と「受け取る」「見送る」。虚夢変転は、所持の淵遺物と汎用素材から材料の枠（2〜4）へ入れ、ランクの計算とカテゴリの確率（％）の見込みを出す。特別な組み合わせに当てはまると、見込みの代わりに予告を出して祈念の欄を隠す。形は試作 `scripts/hollow_relic_proto/`（決定 → §9）。
- **ドックのアイコン**：ホロウの部屋では、使わない「未配置キャラクター」「簡易ステータス編集」を出さない（PR35-11）。ドック全体の並べ替えやまとめ方は通常ルームと共有の部品なので、UI 基盤計画 §7.4 の UI-2f で扱う。

## 5. 仕組みの設計（改訂）

### 5.1 ホロウデータの画面

- メインメニューのデータの欄（`DATA_CARDS`）に、「ユニット管理」「マスターデータ」と並べて「**ホロウデータ**」を置く（画面 `#hollow-data`。開ける人はユニット管理と同じ）。ユニット管理はセッション用だけを扱い、切り替えは付けない。ホロウデータの画面は**別の配色・演出**にする（色は変数で切り替える）。方向は「淵の夜」：濃い藍〜黒の地に、鉱石の淡い光（青緑・紫）と細い銀の線。等級の札や強調には金属色（鉄・銅・銀・金・特異）を差し色に使う（決定 → §9）。部屋の操作盤も同じ配色にする。鉱石の光は青緑に寄せる（試作 `scripts/hollow_data_proto/` の A 案、2026-11-25 決定。テーマ名 `abyss`）。文字の見やすさは共通の決まり（文字4.5:1以上、操作部品の枠3:1以上、E02 Part 17）を守る。ルーム内の待機列の「夜色と金」とは見分けがつくようにする。
- ユニット・編成・ステージ・分類に**区分**（`domain`：`session`／`hollow`）を持たせる。種類は増やさず、検査・履歴・書き出し・取り込みは共通のまま使う。ホロウデータの画面のユニット・編成・ステージ・分類のタブは、ユニット管理の画面の部品を区分 `hollow` で開いたもの（一覧は区分で絞り、新規作成は `hollow` で作る）。
- ユニットが「ホロウかどうか」は区分だけで決める。図鑑は区分が `hollow` のユニットを、ホロウ専用の物として扱う。`hollow` の印はなくす（`enemy`・`known` は残す）。ホロウかどうかは、ユニット資源は区分で決め、ホロウだけの種類（§5.2）はそれ自体がホロウの物（決定 → §9）。
- 配置に使う一覧（`manager/units/runtime.py` の `deployment_store`）を、部屋の種類で絞る。通常ルームの待機列にはセッション用だけ、ホロウの部屋にはホロウ用だけが出る。
- 区分はまたがない（決定 → §9）。ホロウの編成・ステージはホロウのユニット・編成だけを参照する。セッションのユニットを使いたいときは「ホロウへ複製」で、ホロウ側に別の ID のユニットとして作る（行動パターンも写す。以後は別々に直す）。
- ホロウデータの画面には、§5.2 のホロウだけの種類のタブも並べる。ホロウに関する管理はすべてここに集め、ユニット管理・マスターデータの管理画面には切り替えを付けない。タブは「敵（ユニット・編成・ステージ・分類）」「階（Tier・マップ・固定階・イベント・宝箱）」「報酬（淵遺物・ドロップ表・バフ・アイテム）」の組に分ける。敵の4つと Tier・マップ・固定階を開ける。イベント・宝箱と報酬は押せない札を並べる。

### 5.2 ホロウだけのデータの種類（案）

ユニットと同じく、制作者が直接保存し、版と履歴を持つ（承認は通さない）。

| 種類 | 中身 |
|---|---|
| Tier | 区切りの番号（1〜5。1区切り＝10F）、表示名、見た目の説明、強さの補正の係数（HP・攻撃） |
| マップ | Tier の番号（1つの Tier 専用）、名前、説明、画像（マップを選ぶ札の絵）、イベントの重み（通常戦闘・精鋭戦闘・宝箱・魔素だまり）、遭遇表（通常戦闘・精鋭戦闘ごとに「編成ID と重み」）、イベントの表（「魔素だまりの ID と重み」）、宝箱の表（「宝箱の ID と重み」）、淵遺物のカテゴリの出やすさ（カテゴリごとの重み）、ボスの編成とステージ |
| 固定階 | 階の数、種類（町・キャンプ）、演出の文章。ボスはマップが持つ |
| 淵遺物 | 名前、カテゴリ（12種類）、ランク（Ⅰ〜Ⅴ。魔力負荷も同じ数）、対象（全員・条件・N番目）、効果（バフの ID：`Bu-` か `HBu-`）、代償のバフ（空でもよい）、フレーバー、画像 |

| イベント（魔素だまり） | 文章、選択肢（最大4つ。ラベル、判定の技能と難易度、効果と対象、失敗時の効果と対象）。効果は `{kind: buff｜item｜relic, id, battles}`（バフは `battles` 必須）。ベースキャンプはマスにしないので種類を持たない |
| 宝箱 | 文章、ドロップ表の ID |
| ドロップ表 | 行の一覧（アイテムか淵遺物、ID、重み）。レアリティは淵遺物の側に持つ |
| ホロウのバフ（`hollow_buff`、`HBu-01`〜） | マスターデータのバフと同じ項目（名前・説明・フレーバー・効果・既定の持続・分類） |
| ホロウのアイテム（`hollow_item`、`HI-01`〜） | マスターデータのアイテムと同じ項目 |

- ホロウのバフ・アイテムは、マスターデータとは別の、ホロウだけの種類として持つ（上の表）。保存の決まり（直接保存・版・履歴）はほかのホロウの種類と同じで、マスターデータの承認・公開・`--pull`・計画60の規則には触れない。マスターデータの側には何も足さない。
- 共通にするのは、戦闘と同じでないと困る部分だけ：効果（`effect`）の形と検査、画面のフォームと効果の編集部品、効果から文章を作る機能。保存・一覧・採番・履歴はホロウの種類の仕組みを使う。
- ホロウの部屋の戦闘は、マスターデータのバフ・アイテムに加えて、ホロウのバフ・アイテムも読み込む（ID の頭が違うので混ざらない）。ホロウのユニットは、ホロウのアイテムを持てる。
- 図鑑は、ホロウのバフ・アイテムを、ホロウの物として扱う（制作者以外には出さない）。ホロウのスキル・パッシブは作らない（ホロウの敵だけが持つ物は、今の `enemy` の印と出会いで隠す）。
- 効果の参照は `{kind: "buff" | "item", id, battles}` の形にする。`battles` は一時バフの「あと何回の戦闘」（§4.5）。マスターデータのバフ自体には足さない。
- 敵の組み合わせは「役割と重みで1体ずつ組む」のではなく、**遭遇表から編成を引く**（決定 → §9）。精鋭は「精鋭用の編成」として作る。編成なので、ユニット管理の検査・プレビュー・シミュレーターがそのまま使える。同じ顔ぶれが気になったら、遭遇表の行に「型（役割と重み）」を足す形で後から広げられる。

### 5.3 ホロウの部屋

- 部屋は既存の `Room`／`RoomMember`（参加コード、オーナー）を使い、`play_mode: "hollow"` を持つ。中身は通常ルームの仕組み（盤面、キャラクター、待機列の配置処理、戦闘突入・終結、戦闘記録）。
- 作成時に GM PIN を求めず、GM の役割を持たせない（決定 → §9）。部屋の役割はオーナー・ホスト・プレイヤーの3つ。オーナーはホストの譲渡と部屋の管理（参加コード、退出させる、削除）を持つ。バフ・状態の付与、キャラの編集、HP の書き換えといった GM の介入はできない。詰まったときの復旧手段が必要と分かったら、オーナー用の限られた復旧操作を足す。
- ルーム一覧（セッション）には出さない。メインメニューの「ダンジョン」から開く画面（`#dungeon`）に、自分が参加しているホロウの部屋（閉じていない物＝パーティを組んでいるか、ラン中）の一覧・新規作成・参加コードでの参加を置く。画面の上に入口の見出し（上の行に小さく「ホロウダンジョン」、大きく「虚夢の辺縁」。ホロウデータと同じ遺跡の絵。狭い幅では見出しを低くする）、その下に部屋ごとの札（名前、オーナー、ホスト、状態、T1〜T5 の帯で今いる区切り、パーティの名前か顔を6つまで、入る）を並べる（決定 → §9）。
- 部屋の中では、通常ルームの画面（盤面・宣言・解決表示・チャット・アイテム・キャラ詳細）をそのまま使い、その上に**ホロウの操作盤**（今の階、イベント、パーティ、ホスト、推薦ピン、撤退、ドロップの結果）を重ねる（決定 → §9）。マスを選ぶときは盤面の代わりに地図の画面を出し、戦闘の画面とはっきり切り替える（§4.9）。パーティと参加者は、左のアクションドックのアイコンから開く窓で見る（PR35-6。淵遺物の所持は PR35-14 で作る淵遺物の窓で見る）。通常ルームで GM が使うボタン（戦闘突入・戦闘終結・R開始・R終了・待機列）はホロウの部屋では出さない。ダンジョンらしさは操作盤とホロウ用の配色で出し、段階7の仕上げで配置・配色を磨く（画面の骨組みは通常ルームと共有）。

### 5.4 ホストの権限（D01 Part 8 の表の作り直し）

「誰が戦闘を進められるか」を1つの判定関数にまとめる：通常ルームでは GM、ホロウの部屋ではホストとオーナー。ホロウの部屋では、D01 Part 8 の表の操作のうち次をこの判定に通す。

- 解決の開始。解決表示は開始した人が進行する。不在なら接続中のホスト・オーナーが引き継げる。どちらも不在なら接続中の参加者が引き継げる
- ラウンドの自動進行（解決表示の後にラウンド終了と次のラウンド開始）
- 全滅による戦闘の自動終結（勝てば `VICTORY`、全滅なら `DEFEAT`）
- リセット

宣言と駒の操作は、各プレイヤーが自分のキャラクターを操作する。ホストとオーナーは全員のキャラクターを代理で宣言・移動できる（決定 → §9）。通常ルームの「GM は全キャラクターの代理宣言ができる」を、同じ判定関数でホストにも広げる形にする。

### 5.5 1階の流れ

1. ランの開始とボスの後にマップの候補を出す。ホストが選んだマップから、その Tier の地図を作る（§4.9）。この節のホスト操作はオーナーもできる。
2. ホストが、今いるマスから道でつながる次のマスを選ぶ。1F 下り、30F までは生存しているパーティの最大 HP の10%・最大 MP の20%を回復する。
3. 戦闘マスのとき：戦闘の画面へ切り替える → 遭遇表から編成を引く → 待機列の配置処理で敵を出す（前の階の敵は除く。味方の配置は残す）→ 階に応じた強さの補正を付ける（HP の倍率に控えの人数の補正も掛ける。敵用のバフ）→ 戦闘突入の直前に淵遺物・段階の代償・一時バフを付け直す → ラウンドを進める（出撃のキャラが倒れたら、次のラウンドの始めに控えが入れ替わる）→ 全滅で自動終結 → ドロップを引く → 地図の画面へ戻る。
4. 戦闘でないとき：魔素だまり・キャンプ・宝箱を、地図の画面のまま解決する。
5. 解決後は次のマスを選べる。戦闘の外では撤退できる。区切りのボスの報酬を確定した後は、固定階の町や先人のキャンプで回復してから、次の区切りのマップの候補を出す。50F のボスの報酬確定でクリア。

HP・MP・FP は階をまたいで残る。町と先人のキャンプの回復は HP・MP に適用し、戦闘不能からも復帰できる（§4.4）。

### 5.6 ルーム状態に足すもの（案）

```jsonc
"party": { "order": ["char_xxx", "char_yyy"] },
"hollow": {
  "host_user_id": "user_xxx",
  "run": {
    "status": "forming | in_progress | finished",   // forming＝パーティを組んでいる。finished で部屋を閉じる（§4.7）
    "seed": 67890,                              // 候補と地図を引くランの種（サーバー用）
    "floor": 20,
    "party_order": ["char_xxx", "char_yyy"],      // ラン開始時の並び（1〜4番目が出撃、5・6番目が控え。淵遺物の「N番目」はこの順）
    "active": ["char_xxx"],                       // 今の出撃（入れ替わり・戦闘不能で変わる）
    "map_candidates": { "tier": 3, "maps": [{ "map_id": "HM-04", "name": "結晶の森", "description": "" }] },  // 選択待ちの間だけ

      "rows": [[{ "id": "n20a", "floor": 20, "type": "boss", "next": [] }]],  // 最後の段だけ掲載
      "current": "n20a", "visited": ["n19a", "n20a"]
    },
    "relics": ["HR-01"],
    "materials": { "1": 2 },
    "mana_load": 23,
    // ボス報酬の選択中は map_candidates の代わりに "reward": { "floor": 20, "relic_ids": ["HR-12", "HR-18"] },
    // 19Fの合成中なら reward の代わりに "fusion": { "floor": 19, "wishes_left": 1, "count": 0 }
    "temp_buffs": [{ "char_id": "...", "buff_id": "...", "battles_left": 2 }],

```

`current_event` は、魔素だまりなら `{type: "miasma", resolved: false, name, text, choices}`、宝箱なら `{type: "chest", resolved: false, name, text, loot}`（抽選済みのアイテムまたは淵遺物1件）、町なら `{type: "town", resolved: true, name, text, recovery, boss_name}`。魔素だまりと宝箱は確定後に `result` を残す。先人のキャンプは `town` と同じ回復結果の形で `type: "camp"` を使う。

真実はメモリ上のルーム状態で、保存は今のデバウンスに乗せる。

### 遊ぶデータの作り方と時期（2026-11-27）

実装の段階とは別の作業として、別のチャットで進める。実装の完了を待たず、T1 から本番と同じ質で作り、遊びながら深い Tier へ広げる。

| 時期 | データの作業 |
|---|---|
| 今〜段階5の実装中 | 設計表：Tier ごとのマップの構想（名前・雰囲気・敵の系統・ボス・出やすいカテゴリ）、淵遺物のカテゴリごとの効果の型とランクでの伸び方、魔力負荷の段階と代償、特別な組み合わせの候補 |

| 段階6の後 | T1 のイベントと宝箱。T2 を一式 |
| 段階7〜8 | T3〜T5 を作り、シミュレーターで係数とデータを直す |

- 淵遺物は型（カテゴリごとの効果の形と、ランクでの伸び方）を先に決め、55個（11カテゴリ×Ⅰ〜Ⅴ）は型から作る。手で作り込むのは特別な組み合わせ・出身強化・代償つきの遺物。
