# 計画51：読みにくい言葉へのルビ

作成日: 2026-10-23
状態: 着手（2026-10-23）。§3の読みと§4の振る場所はユーザー確定済み。ルビを振った版も第1版のままとする（ユーザー決定）。

## 1. 目的

サーバーメンバーから、「震盪」「荊棘重絡」など、人によって読みに困る言葉があると指摘があった（2026-10-23）。基本ルールブックとセッション操作ガイドで、読みにくい言葉にルビを振り、読み方で迷わないようにする。

あわせて、言葉と読みの対応を1か所にまとめ、今後のアプリの用語図鑑や説明動画の読み上げにも同じ読みを使えるようにする。

## 2. 対象

- 2冊の本文・見出し・表・巻末（`typst_manual/全体マニュアル/`、`typst_manual/操作ガイド/`）。
- 用語辞典のシート（Google Sheets）とアプリの用語図鑑は、§7の任意の段階で扱う。この計画の第1段では変更しない。

## 3. 読みの正本

- 言葉と読みの対応表を `typst_manual/readings.typ` に1つだけ作る。2冊はこの表から読みを引く。
- 表に載せる読みは、ユーザーが確定したものだけにする。推定の読みは載せない。推定しかない言葉は、ユーザーに確認するまで振らない。

### 3.1 ユーザー確定の読み（2026-10-23）

| 言葉 | 読み |
| --- | --- |
| 盛夏と共鳴る高揚（エムリダの恩恵） | 「共鳴る」は「ともなる」 |
| 砂海を流離う行人（アル・カルメイルの恩恵） | さかいをさすらうこうじん |
| 活力の行き重なる落合（フローディアスの恩恵） | 「行き重なる落合」は「ゆきかさなるおちあい」 |
| 狭霧に息づく神秘（アルトマギアの恩恵） | 「狭霧」は「さぎり」 |
| 神樹の恩寵（マホロバの恩恵） | 「神樹」は「しんじゅ」 |
| 綿津見 | ワダツミ |
| 辰砂亜 | シンシア |

国名の扱い（ユーザー決定）：ワダツミとシンシアは、国名を初めて出すときに漢字で書いてルビを振る（綿津見、辰砂亜）。一度出てからは、カタカナ表記を主にする。

§5の1のスクリプトで新しく見つかった言葉は、ユーザーが読みを確定してから振る。

## 4. 振る場所（2026-10-23ユーザー確定）

- 各章で、その言葉が最初に出たときに振る。毎回は振らない。
- 節の見出しにも振る。目次やリンクから飛んできた人が最初に見る場所のため。
- 巻末の用語索引と、状態異常の効果の早見表では、読みを振るか、読みの列を足す。調べるときに引く場所のため。
- 国名のワダツミ・シンシアは§3.1のとおり、初出だけ漢字＋ルビにする。

## 5. 進め方

1. **洗い出しの仕組み**：2冊の原稿と用語辞典の言葉を集め、文化庁の「常用漢字表」（2010年告示）にない漢字を含む言葉をスクリプトで挙げる。常用漢字表の一覧は、出典を明記してリポジトリに置く。常用漢字だけでも組み合わせで読みにくい言葉（「重絡」など）は、自動では拾えないため、§3.2の手作業の候補とサーバーメンバーの指摘を足す。
2. **読みの確定**：1の結果と§3.2をユーザーに提示し、振る言葉と読みを確定する。確定した分を `readings.typ` に入れる。
3. **ルビの部品**：Typst には標準のルビ機能がないため、`manual_theme.typ` にルビの部品を作る。外部パッケージは、組版の再現性（`typst_manual/README.md` の組版環境）を保つため使わない。行の間隔・ページの空白の目安が崩れないことを、見本で確かめてからユーザーに見せる。
4. **当てはめ**：§4の決まりで2冊に振る。各章の初出の判定は、手で付けるより部品側で自動にできるなら、そうする。
5. **確認**：2冊を組み直し、全ページを画像で確認する。ページ数の変化と、空白が増えたページを記録する。

## 6. 受け入れ条件

- [ ] 読みの正本が `readings.typ` の1か所にあり、ユーザーが確定した読みだけを載せている。
- [ ] §4の決まりのとおりに2冊へルビが振られている。
- [ ] ワダツミ・シンシアが、初出だけ漢字＋ルビ、以降はカタカナになっている。
- [ ] 行の間隔の乱れ・ルビの重なりがなく、空白調整の目安が崩れていない。
- [ ] 組版の警告がなく、文字コード・文字化け・差分の検査を通る。

## 7. 任意の段階：アプリの用語図鑑と動画

- 用語辞典のシートに「読み」の列を足し、アプリの用語図鑑で読みを表示する。シートの編集はユーザーの作業になる。
- 説明動画の読み上げでも、`readings.typ` と同じ読みを使う。
- どちらも、本のルビが終わってから検討する。
