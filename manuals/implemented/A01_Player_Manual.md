## 1. 始める前に

### 1.1 ログインと新規登録

1. GMから配布されたURLにブラウザでアクセスします。ログイン画面には「ログイン」「新規登録」「復旧」の3つのタブがあります。
2. 初めての場合は「新規登録」で、ログインID・表示名・パスワード（10文字以上）を入力し、「アカウント作成」を押します。
3. 登録済みの場合は「ログイン」で、ログインIDとパスワードを入力します。
4. ログインするとロビー（ルーム一覧）が表示されます。

同じブラウザには端末トークンが保存されるため、ログアウトしない限り、次回は自動的にログインした状態で始まります。表示名はロビーの「ユーザー設定」でいつでも変更できます。

### 1.2 ログインできないとき

「復旧」タブから、次のどちらかの方法でログインし直せます。

- **復旧コード**：アカウント作成時に一度だけ表示される復旧コード（`GEM-XXXX-XXXX` 形式）と名前を入力し、「復旧コードでログイン」を押します。ログイン後にログインID・パスワードを設定できます。
- **ワンタイムコード**：パスワードを忘れた場合は、アプリ管理者にワンタイムコードの発行を依頼します。コードは10文字で、発行から15分間有効です。「ワンタイムコードで再設定」から新しいパスワードを設定します。

### 1.3 ログアウト

ロビー右上の「ログアウト」を押し、確認画面で「ログアウト」を選びます。ログアウトすると、この端末に保存した端末トークンも失効するため、次回はログインIDとパスワードでログインします。

### 1.4 ルームに入る

1. ロビーのルーム一覧で、参加するルームを選びます。
2. 初めて参加するルームでは「参加」を押し、GMから伝えられた参加コードを入力します。
3. 参加済みのルームでは「入室」を押します。
4. 入室時に「GMとして入室しますか？」と表示されたら「プレイヤー」を選びます。「GM」を選ぶとGM PINの入力を求められます。

### 困ったとき（始める前に）

| 症状 | 確かめること |
| --- | --- |
| ログイン画面に戻ってしまう | ログアウトした端末では、ログインIDとパスワードでログインし直します |
| パスワードを忘れた | 復旧コードを使うか、アプリ管理者にワンタイムコードを依頼します（1.2） |
| ルーム一覧に参加したいルームがない | 非公開のルームは一覧に表示されません。GMに参加方法を確認します |
| 参加コードが通らない | コードが再発行・失効されていないか、GMに確認します |

## 2. キャラクターを用意する

### 2.1 キャラクターを作ってアカウントに保存する

1. ロビー左下の「マイキャラクター」を押します。
2. 「＋ 新規作成」を押すと、キャラ作成ツールが開きます。作成済みのキャラクターを直す場合は、そのキャラクターの「📝」（キャラ作成ツールで編集）を押します。
3. キャラ作成ツールで能力値とスキルを決め、「☁️ アカウントに保存」を押します。保存したキャラクターを「持ちキャラ」と呼びます。

キャラ作成ツールでは、「📋 コピー」でキャラクターのJSONをコピーしたり、「💾 保存 (.json)」でファイルに保存したりすることもできます。マイキャラクター画面の「📤」（JSONを出力）でも、保存済みの持ちキャラをJSONとして取り出せます。

作成のルール（能力値、取得予算、初期スキル）は卓上ルール本の「キャラクター作成」を参照してください。

### 2.2 キャラクターをルームに追加する

1. ルームに入り、画面左端のアイコン列（アクションドック）の「＋」（キャラクターを追加）を押します。
2. 「味方を追加」を選びます。
3. 「保存済みの持ちキャラから選ぶ」で追加するキャラクターを選び、「追加」を押します。

ルームに追加したキャラクターは、持ちキャラのコピーです。ルームの中でHPが減るなどしても、持ちキャラ本体は変わりません。セッションで得た経験値は、セッションの後に「成果を反映」で持ちキャラへ書き戻します（5.1）。

追加した直後のキャラクターは盤面に置かれていません。ドックの「📦」（未配置キャラクター）を開き、そのキャラクターの「配置」を押すと盤面に置かれます。GMが配置を行う卓もあるので、GMの案内に従ってください。配置した後は、自分のキャラクターの駒をドラッグして動かせます。

### 2.3 JSONで追加する

持ちキャラを使わずに追加する場合は、2.2の手順2の次の画面で、キャラクターのJSONを貼り付けるか、「ファイルから読み込み」でJSONファイルを選び、「味方として追加」を押します。この方法で追加したキャラクターは持ちキャラと結び付かないため、「成果を反映」は使えません。

### 困ったとき（キャラクターを用意する）

| 症状 | 確かめること |
| --- | --- |
| 持ちキャラが一覧に出ない | キャラ作成ツールで「☁️ アカウントに保存」を押したか |
| 追加したキャラクターが盤面にいない | 追加直後は未配置です。「📦」の「配置」を押すか、GMの配置を待ちます |
| 「成果を反映」が表示されない | 持ちキャラから追加したキャラクターか（JSONで追加したキャラクターは対象外） |

## 3. 画面を読む

### 3.1 戦闘画面の配置

| 場所 | 内容 |
| --- | --- |
| 画面左端のアイコン列（アクションドック） | 操作のボタンが縦に並ぶ（下表） |
| 中央の盤面 | キャラクターの駒を置く場所。戦闘中は駒の上にスロット（速度値の数字）が付く |
| 盤面の左下 | 「＋」「－」で拡大・縮小、「⟲」で表示位置と倍率を元に戻す |
| 画面右側の列の一番上 | 戦闘の状態表示（「戦闘準備中」または「戦闘中」）と「戦闘記録」 |
| 画面右側の列 | チャットとログ。ダイスの結果、スキルの効果、ダメージなどが表示される |

アクションドックの主なボタンです。

| ボタン | 内容 |
| --- | --- |
| ⚡ | 即時発動スキルを使う |
| 🎒 | アイテムを使う |
| 📝 | HP・MPなどを簡易的に編集する |
| ＋ | キャラクターを追加する |
| 📦 | 未配置のキャラクターを確認する |
| 🏹 | 盤面の矢印の表示を切り替える |
| 📚 | 用語図鑑を開く（[A04](A04_Glossary_Tutorial.md)） |
| ♪ | 効果音の有無を切り替える |

### 3.2 キャラクター詳細

盤面の駒をダブルクリックすると、キャラクター詳細が開きます。未配置のキャラクターは、盤面に置いてから開きます。

- **名前とタグ**：名前の下にタグが表示されます。プレイヤーキャラクターのタグは、出身・ボーナス国（`出身:国名`）と取得済みの輝化スキルから自動で作られ、プレイヤーは編集できません。赤字・取り消し線のタグは、GMが無効にしているタグです。
- **パラメータ**：筋力・生命力・体格・精神力・敏捷・直感・経験・物理補正・魔法補正。
- **出身情報**：出身国と、適用されているボーナス国。
- **特殊効果・バフ**：現在かかっている効果。見出しを押すと、説明と残りラウンドが開きます。
- **スキル**：所持スキルの一覧。押すと詳細が表示されます。

右上の「⚙」（設定）からは、立ち絵の変更、駒の大きさの変更、未配置に戻す、所有権の譲渡、削除などを行えます（表示される項目は権限によって変わります）。持ちキャラから追加したキャラクターには「成果を反映」も表示されます（5.1）。

### 3.3 効果の表示の読み方

- **ダメージ増減のバフ**：説明欄に、受けるダメージの増減（DaIn／DaCut）と、与えるダメージの増減（DaOut／DaOutDown）が表示されます。
- **付与スキル**：他のキャラクターから付与されたスキルは、スキル一覧に黄色で表示されます。押すと「付与スキル」の表示と、残りラウンドまたは残り使用回数が出ます。同じスキルを付与し直されると、残りが上書きされます。
- **召喚体**：ラウンド数に制限のある召喚体は、特殊効果・バフの欄に「残りX R」が表示されます。期限切れや戦闘不能で消えた召喚体は、未配置の一覧にも表示されません。
- **ダイス威力の変化**：効果によってダイスの面数が変わると、ログに `(4+1d8)` のように変わった後のダイスが表示されます。

それぞれの効果のルール（付与・召喚の処理、状態異常の扱い）は卓上ルール本を参照してください。内部の処理仕様は[B02](B02_Skill_Logic_Extensions.md)にあります。

### 3.4 チャットからダイスを振る

チャット欄の先頭に次のコマンドを書くと、サーバーでダイスを振り、結果をログに表示します。

| 入力 | 公開範囲 | 例 |
| --- | --- | --- |
| `/roll <式>` または `roll <式>` | 通常公開ログ | `/roll 2d6+3` |
| `/sroll <式>` または `sroll <式>` | 秘匿ログ | `/sroll 1d100` |

表示は `<式> → <出目展開> = <合計>` の形式です（例：`2d6+3 → (4+5)+3 = 12`）。投稿者名はサーバー側の在室情報から決まります。

- コマンドとして扱うのは、投稿の先頭にある `roll` / `/roll` / `sroll` / `/sroll` だけです。
- ダイス式がない場合、式のない空コマンドは無視し、文字が残る場合は通常のチャットとして送ります。
- 1つの投稿に複数のコマンドを書いても、先頭のコマンドだけを解釈します。

仕様の詳細は[F01](F01_Operations_Manual.md) Part 8にあります。

### 困ったとき（画面を読む）

| 症状 | 確かめること |
| --- | --- |
| キャラクター詳細が開かない | 駒をダブルクリックしているか。未配置のキャラクターは盤面に置いてから開きます |
| 盤面が見えない位置にずれた | 盤面左下の「⟲」で元に戻します |
| 表示が古いように見える | ブラウザを再読み込みします。データはサーバーに保存されています |

## 4. 戦闘・探索を操作する

### 4.1 戦闘の流れとプレイヤーの操作

通常ルームの戦闘は、次の順に進みます。プレイヤーが操作するのは「宣言」だけで、ほかはGMが進めます。

1. **戦闘準備中**：画面右側の列の状態表示が「戦闘準備中」のあいだは、ラウンドは始まりません。
2. **戦闘突入とラウンド開始**（GM）：GMが「戦闘突入」を行い、ラウンドを開始すると、状態表示が「戦闘中」になり、駒の上にスロットが付きます。スロットの数字は、そのラウンドの速度値です。
3. **選択フェーズ**（プレイヤー）：自分のキャラクターのスロットごとに、スキルと対象を宣言します（4.2）。速い順を待つ必要はありません。
4. **解決フェーズ**（GM）：宣言がそろうと、GMが解決を始めます（4.3）。
5. **ラウンド終了**：解決が終わると、ラウンド終了時の処理が自動で行われます。次のラウンドはGMが開始します。
6. **戦闘終結**（GM）：GMが戦闘を終えると、結果が表示され、状態表示が「戦闘準備中」に戻ります（4.4）。

戦闘を始めても、HP・MP・FPは自動で回復したり0になったりしません。シナリオで回復などが指定されている場合は、GMの案内に従います。速度値の決め方、マッチと一方攻撃、ダメージ、FPの獲得は卓上ルール本の戦闘の章を参照してください。

### 4.2 宣言する

宣言は、選択フェーズのあいだに盤面のスロットから行います。宣言パネルの上部に「1 使用者」「2 スキル」「3 対象」の手順と、次に行う操作の案内が表示されます。

1. **使用者を選ぶ**：自分のキャラクターの駒のスロットをクリックします。宣言パネルが開き、そのキャラクターのスキルがカードで並びます。
2. **スキルを選ぶ**：使用するスキルのカードをクリックします。カードの一覧が、そのスキルの詳細（威力レンジ、コマンドなど）に切り替わります。
3. **対象を選ぶ**：対象にするキャラクターの駒のスロットをクリックします。自分を対象にするスキルや広域スキルでは、この手順は要りません。
4. 「内容を確認して『宣言』を押してください。」と表示されたら、内容を確認して「宣言」を押します。

- 使用者を選んだ後、スキルより先に対象を選ぶこともできます。その場合は、その対象に使えるスキルだけが表示されます。対象を変えたときに使えないスキルが選ばれていると、選択が解除されます。
- 使用コストが足りないスキルのカードは薄く表示され、選べません。HPを使用コストにするスキルも、HPが足りなければ選べません。
- 選んだスキルを変えるときは、スキル名の横の「↩」でカードの一覧に戻ります。
- 宣言した後でも、解決が始まる前なら、スロットを選び直して内容を変え、「再宣言」で確定し直せます。宣言済みのスロットをダブルクリックすると、宣言した内容を開いた状態から選び直せます。
- 自分のキャラクター以外のスロットを開いた場合、ボタンは「閲覧」になり、宣言できません。
- 威力レンジは予想の幅で、ダイスを振った結果ではありません。

単体の行動は、互いのスロットが相手を対象にしていれば原則としてマッチになり、そうでなければ一方攻撃になります。引き寄せなどで対象が変わることがあるため、宣言後の矢印も確認してください。対象の決まり方の詳細は卓上ルール本と[B03](B03_SelectResolve_Spec.md)を参照してください。

### 4.3 解決を見る

宣言がそろうと、GMが解決を始めます。解決の表示を進めるのはGMで、プレイヤーは表示を見て待ちます。

- 解決の始めに「戦闘開始」の表示が入ります。
- 解決パネルに、マッチ・一方攻撃・広域の結果が1件ずつ表示されます。威力は「レンジ → 実際の威力」の順に出ます。
- 一方攻撃では、受ける側のスキルは表示されず、「Xの一方攻撃」と表示されます。
- ダメージは「ダイス由来」と「効果由来」に分けて表示されます。効果由来のダメージは「亀裂」「破裂爆発」などの内訳名で表示されます。
- 非ダメージのスキルは、命中してもHPは減りません。命中時の追加効果（バフや状態異常の付与）は通常どおり処理されます。
- ログの「強硬攻撃」は、通常のマッチに敗れた後の専用の追撃です。回避の差し込みがあってもなくても「強硬攻撃」と表示されます。牽制や回避で止められた場合は、不発の理由がログに出ます。
- 解決によるHP・FPの変化やラウンド終了時の効果は、チャットのログで確認できます。

### 4.4 ラウンドの終わりと戦闘の終わり

ラウンドの解決が終わると、ラウンド終了時の効果（スキルの終了時効果、出身ボーナスなど）が自動で処理されます。

GMが「戦闘終結」を行うと、全員の画面に「VICTORY」「DEFEAT」「RETREAT」「INTERRUPTED」のいずれかが表示されます。HP・MP・FP・盤面の配置は保持されたまま、状態表示が「戦闘準備中」に戻り、次の戦闘はラウンド1から始まります。

画面右側の列の一番上にある「戦闘記録」では、そのルームで終えた戦闘の結果、開始・終了時刻、完了したラウンド数、キャラクターごとの与えたダメージと受けたダメージを確認できます。記録の削除はGMだけが行えます。

### 4.5 アプリが自動で処理する効果

次の効果は、条件を満たすとアプリが自動で処理します。プレイヤーが操作する必要はありません。内容は卓上ルール本の該当箇所を正とします。

| 効果 | アプリの処理 | ルールの参照先 |
| --- | --- | --- |
| 出身ボーナス | ラウンドの開始時・終了時、攻撃時などに自動で適用。キャラクター詳細で出身とボーナス国を確認できる | 卓上ルール本「出身国ボーナス」 |
| 加速・減速 | 次のラウンド開始時の速度値に加算・減算し、反映後に解除 | 卓上ルール本「速度値」 |
| マッチ勝利時のFP | 勝った側のFPを自動で増やす | 卓上ルール本「FPの付き方早見表」 |
| 防御と回避、回避どうしが向き合った場合 | 両方を不発として処理（使用コストは減らず、効果も発動しない） | 卓上ルール本の不発の説明 |
| 味方を対象にするスキル | 引き寄せの処理に参加しない。同じ陣営どうしで互いを対象にしても、マッチにならず一方で処理 | [B03](B03_SelectResolve_Spec.md) §10.6（卓上ルール本には未収録） |

### 4.6 探索パート

戦闘以外の場面では、GMが探索パートに切り替えます。駒を自由な位置に置け、背景画像が表示されます。

- **視点の移動**：背景の何もないところをドラッグします。
- **拡大・縮小**：マウスホイール、または盤面左下の「＋」「－」を使います。「⟲」で元に戻します。
- **キャラクター詳細**：駒をダブルクリックします。
- **探索判定**：ドックの「🎲」（探索判定）から、技能を選んでダイスを振ります。
- **簡易編集**：ドックの「📝」からHP・MPなどを簡易的に編集します。

探索判定の式と目標値は卓上ルール本の「判定ルール」を参照してください。

### 困ったとき（戦闘・探索を操作する）

| 症状 | 確かめること |
| --- | --- |
| スロットが表示されない | 状態表示が「戦闘中」で、ラウンドが始まっているか。キャラクターが盤面に置かれているか |
| スロットを押しても宣言パネルが開かない | 自分のキャラクターのスロットか。解決が始まった後ではないか |
| スキルのカードが選べない | 使用コスト（FP・MP・HP）が足りているか |
| 宣言ボタンが押せない | 対象のスロットを選んだか |
| 解決が進まない | 解決を進めるのはGMです。GMの操作を待ちます |

## 5. セッションの後

### 5.1 成果を反映する

持ちキャラから追加したキャラクターは、セッションの後に、キャラクター詳細の「⚙」から「成果を反映」を行うと、獲得した経験値（ルームによってはアイテムも）が持ちキャラへ書き戻されます。

- 反映は、キャラクターの持ち主またはGMが行えます。
- 1回のセッションにつき1回だけ反映できます。反映済みの場合は「反映済みです」と表示されます。

### 5.2 持ちキャラを成長させる

ロビー左下の「マイキャラクター」で、成長させるキャラクターの「🌱」（成長）を押します。

- 経験値で戦闘スキルを、通過点で輝化スキルを取得できます。それぞれの予算は別に管理されます。
- 筋力・生命力・体格・精神力・敏捷を、経験値で直接上げることはできません。
- キャラ作成ツールで編集し直す場合も、能力値を経験値で上げる手順にはなりません。編集画面の予算表示には取得済みスキルの分が含まれるため、残りの経験値とは区別してください。

成長のルールは卓上ルール本の「継続と成長」を参照してください。

### 困ったとき（セッションの後）

| 症状 | 確かめること |
| --- | --- |
| 「成果を反映」が表示されない | 持ちキャラから追加したキャラクターか |
| 「反映済みです」と表示される | そのセッションの成果は反映済みです |

## 付録A 共有された戦闘専用プリセット

- 公開、GM共有、または自分へ個別に共有されたプリセットは、与えられた権限の範囲で閲覧できます。
- 閲覧者は内容の確認、複製、通常のJSON出力を行えますが、元のプリセットの編集・削除・再共有はできません。
- ルームでプリセットを戦闘に配置できるのは、そのルームのowner・gmです。通常のプレイヤーには、戦闘の表示と操作に必要な情報だけが配信されます。
