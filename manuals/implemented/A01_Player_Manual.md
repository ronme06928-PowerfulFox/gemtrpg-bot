## 1. 始める前に

### 1.1 ログインと新規登録

1. GMから配布されたURLにブラウザでアクセスします。ログイン画面には「ログイン」「新規登録」「復旧」の3つのタブがあります。
2. 初めての場合は「新規登録」で、ログインID・表示名・パスワード（10文字以上）を入力し、「アカウント作成」を押します。
3. 登録済みの場合は「ログイン」で、ログインIDとパスワードを入力します。
4. ログインするとロビー（ルーム一覧）が表示されます。

アカウントを作った直後に「復旧コード」の画面が表示されます。再読み込みや次のログインでは同じコードを再表示・再発行しません。コードを控えて「控えました」を押します。

同じブラウザには端末トークンが保存されるため、ログアウトしない限り、次回は自動的にログインした状態で始まります。表示名はロビーの「ユーザー設定」でいつでも変更できます。

### 1.2 ログインできないとき

「復旧」タブから、次のどちらかの方法でログインし直せます。

- **復旧コード**：「復旧コード」の画面に一度だけ表示されるコード（`GEM-XXXX-XXXX` 形式）と登録時の名前を入力し、「復旧コードでログイン」を押します。ログイン後にログインID・パスワードを設定できます。
- **ワンタイムコード**：パスワードを忘れた場合は、アプリ管理者にワンタイムコードの発行を依頼します。コードは10文字で、発行から15分間有効です。「ワンタイムコードで再設定」から新しいパスワードを設定します。

### 1.3 ログアウト

ロビー右上の「ログアウト」を押し、確認画面で「ログアウト」を選びます。ログアウトすると、この端末に保存した端末トークンも失効するため、次回はログインIDとパスワードでログインします。

### 1.4 ルームに入る

1. ロビーのルーム一覧で、参加するルームを選びます。
2. 初めて参加するルームでは「参加」を押し、GMから伝えられた参加コードを入力します。参加コードが設定されていないルームでは入力は求められません。一覧に表示され、新規参加できるのはGMが公開（listed）にしたルームだけです。
3. 参加済みのルームには「参加者」と表示され、「入室」を押して入ります。
4. 入室時に「GMとして入室しますか？」と表示されたら「プレイヤー」を選びます。「GM」を選ぶとGM PINの入力を求められます。

### 困ったとき（始める前に）

| 症状 | 確かめること |
| --- | --- |
| ログイン画面に戻ってしまう | ログアウトした端末では、ログインIDとパスワードでログインし直します |
| パスワードを忘れた | 復旧コードを使うか、アプリ管理者にワンタイムコードを依頼します（1.2） |
| ルーム一覧に参加したいルームがない | 非公開のルームは一覧に表示されません。GMに参加方法を確認します |
| 参加コードが通らない | コードが再発行・失効されていないか、GMに確認します |

## 2. キャラクターを用意する

### 2.1 キャラクターを作ってアカウントに保存する

1. ロビー左下の「マイキャラクター」を押します。
2. 「＋ 新規作成」を押すと、キャラ作成ツールが開きます。作成済みのキャラクターを直す場合は、そのキャラクターの「📝」（キャラ作成ツールで編集）を押します。
3. キャラ作成ツールで能力値とスキルを決め、ページ下部「データ入出力」の「☁️ アカウントに保存」を押します。「アカウントに保存しました。」と表示されます。保存したキャラクターを「持ちキャラ」と呼びます。

開いたままのマイキャラクター画面は自動で更新されません。閉じて開き直すと一覧に表示されます。一覧の各キャラクターには「🌱」（成長）「📝」（編集）「📤」（JSONを出力）「🗑️」（削除）があります。

キャラ作成ツールでは、「📋 コピー」でキャラクターのJSONをコピーしたり、「💾 保存 (.json)」でファイルに保存したりすることもできます。マイキャラクター画面の「📤」（JSONを出力）でも、保存済みの持ちキャラをJSONとして取り出せます。

作成のルール（能力値、取得予算、初期スキル）は卓上ルール本の「キャラクター作成」を参照してください。

### 2.2 キャラクターをルームに追加する

1. ルームに入り、画面左端のアイコン列（アクションドック）の「➕」（キャラクター追加）を押します。
2. 「味方を追加」を選びます。
3. 次の画面の下にある「保存済みの持ちキャラから選ぶ」で追加するキャラクターを選び、「追加」を押します。チャットに「（キャラクター名） [味方 1] が戦闘に参加しました。」と表示されます。

ルームに追加したキャラクターは、持ちキャラのコピーです。ルームの中でHPが減るなどしても、持ちキャラ本体は変わりません。セッションで得た経験値は、セッションの後に「成果を反映」で持ちキャラへ書き戻します（5.1）。

追加した直後のキャラクターは盤面に置かれていません。ドックの「📦」（未配置キャラクター）を開き、そのキャラクターの「配置」を押すと盤面に置かれます。GMが配置を行う卓もあるので、GMの案内に従ってください。配置した後は、自分のキャラクターの駒をドラッグして動かせます。駒が画面に見えないときは、盤面の何もないところをドラッグして表示位置を動かします。「⟲」で倍率0.6に戻し、盤面の中央を表示領域の中央へ合わせます。

### 2.3 JSONで追加する

持ちキャラを使わずに追加する場合は、2.2の手順2の次の画面で、キャラクターのJSONを貼り付けるか、「ファイルから読み込み」でJSONファイルを選び、「味方として追加」を押します。この方法で追加したキャラクターは持ちキャラと結び付かないため、「成果を反映」は使えません。

### 困ったとき（キャラクターを用意する）

| 症状 | 確かめること |
| --- | --- |
| 持ちキャラが一覧に出ない | キャラ作成ツールで「☁️ アカウントに保存」を押したか。マイキャラクター画面を閉じて開き直したか |
| 追加したキャラクターが盤面にいない | 追加直後は未配置です。「📦」の「配置」を押すか、GMの配置を待ちます |

## 3. 画面を読む

### 3.1 戦闘画面の配置

| 場所 | 内容 |
| --- | --- |
| 画面左端のアイコン列（アクションドック） | 操作のボタンが縦に並ぶ（下表） |
| 中央の盤面 | キャラクターの駒を置く場所。戦闘中は駒の上にスロット（速度値の数字）が付く |
| 盤面の左下 | 「＋」「－」で拡大・縮小、「⟲」で倍率0.6と盤面中央の表示へ戻す |
| 画面右側の列の一番上 | 戦闘の状態表示（「戦闘準備中」または「戦闘中」）と「戦闘記録」 |
| 画面右側の列 | チャットとログ。ダイスの結果、スキルの効果、ダメージなどが表示される |

アクションドックの主なボタンです。

| ボタン | 内容 |
| --- | --- |
| ⚡ | 即時発動スキルを使う |
| 🎒 | アイテムを使う |
| 📝 | HP・MPなどを簡易的に編集する |
| ＋ | キャラクターを追加する |
| 📦 | 未配置のキャラクターを確認する |
| 🏹 | 盤面の矢印の表示を切り替える |
| 📚 | 用語図鑑を開く（[A04](A04_Glossary_Tutorial.md)） |
| ♪ | 効果音の有無を切り替える |

### 3.2 キャラクター詳細

盤面の駒をダブルクリックすると、キャラクター詳細が開きます。未配置のキャラクターは、盤面に置いてから開きます。

- **名前とタグ**：名前の下にタグが表示されます。プレイヤーキャラクターのタグは、出身・ボーナス国（`出身:国名`）と取得済みの輝化スキルから自動で作られ、プレイヤーは編集できません。赤字・取り消し線のタグは、GMが無効にしているタグです。
- **パラメータ**：筋力・生命力・体格・精神力・敏捷・直感・経験・物理補正・魔法補正。
- **出身情報**：名前の下のタグで、出身国と適用されているボーナス国を確認します。Parametersの下に別の出身欄はありません。
- **特殊効果・バフ**：現在かかっている効果。見出しを押すと、説明と残りラウンドが開きます。
- **スキル**：所持スキルの一覧。押すと詳細が表示されます。

右上の「⚙」（設定）からは、立ち絵の変更、駒の大きさの変更、未配置に戻す、所有権の譲渡、削除などを行えます（表示される項目は権限によって変わります）。所有権を譲渡すると、移動・削除・駒サイズ変更の操作権限も新しい持ち主へ移ります。元の持ち主は操作できなくなります（GMの代理操作は維持）。持ちキャラから追加したキャラクターには「成果を反映」も表示されます（5.1）。

### 3.3 効果の表示の読み方

- **ダメージ増減のバフ**：効果名を押すと、受ける・与えるダメージの増減が文章で表示されます。DaIn／DaCut／DaOut／DaOutDownは内部の識別用で、画面で探す項目名ではありません。
- **付与スキル**：他のキャラクターから付与されたスキルは、スキル一覧に黄色で表示されます。押すと「付与スキル」の表示と、残りラウンドまたは残り使用回数が出ます。同じスキルを付与し直されると、残りが上書きされます。
- **召喚体**：ラウンド数に制限のある召喚体は、特殊効果・バフの欄に「残りX R」が表示されます。期限切れや戦闘不能で消えた召喚体は、未配置の一覧にも表示されません。
- **ダイス威力の変化**：効果によってダイスの面数が変わると、ログに `(4+1d8)` のように変わった後のダイスが表示されます。

それぞれの効果のルール（付与・召喚の処理、状態異常の扱い）は卓上ルール本を参照してください。内部の処理仕様は[B02](B02_Skill_Logic_Extensions.md)にあります。

ドックの「📚」から用語図鑑を開き、検索欄で用語を絞り込めます。一覧の項目やスキル説明内の用語リンクを押すと、用語の説明と関連用語が表示されます。

### 3.4 チャットからダイスを振る

画面右側のチャット欄に式を入力し、「送信」またはEnterでダイスを振ります。PC Web版の通常の入力では、まずブラウザがダイス式を判定し、結果をログへ送ります。

| 入力 | 公開範囲 | 例 |
| --- | --- | --- |
| `/roll <式>`（短縮形 `/r <式>`）、または式だけ | 通常公開ログ | `/roll 2d6+3`、`2d6+3` |
| `/sroll <式>`（短縮形 `/sr <式>`） | 画面上は投稿者とGMに結果を表示し、ほかのPLには「（シークレットダイス）」を表示 | `/sroll 1d100` |

ブラウザで判定した結果は、`[投稿者名] <式> = <出目展開> = <合計>` の形式です（例：`[投稿者名] 2d6+3 = (4+5)+3 = 12`）。ダイス数と面数は半角で明記します。

- スラッシュなしの `roll <式>` / `sroll <式>` はサーバー側の `request_chat` で判定し、`<式> → <出目展開> = <合計>` と表示します。ブラウザ側の表示形式と区別します。
- ブラウザ側は `/roll`・`/r`・`/sroll`・`/sr` と式だけの入力を扱い、`request_log` に結果を送ります。先頭のコマンド以外の解釈や不正な式の挙動は、通常の操作手順では案内しません。
- 実装根拠：`static/js/visual/visual_ui.js::setupVisualSidebarControls`、`static/js/battle/utils/MathUtils.js::rollDiceCommand`、`events/socket_main.py::handle_chat`。2026-10-19に通常ルームのPLで `/roll 2d6+3`・`/sroll 1d100`・`roll 1d6` の入力と表示を実機確認。

仕様の詳細は[F01](F01_Operations_Manual.md) Part 8にあります。

### 困ったとき（画面を読む）

| 症状 | 確かめること |
| --- | --- |
| キャラクター詳細が開かない | 駒をダブルクリックしているか。未配置のキャラクターは盤面に置いてから開きます |
| 盤面が見えない位置にずれた | 何もないところをドラッグして表示位置を動かすか、「－」で縮小します。「⟲」で倍率0.6と盤面中央の表示へ戻します |
| 表示が古いように見える | ブラウザを再読み込みします。データはサーバーに保存されています |

## 4. 戦闘・探索を操作する

### 4.1 戦闘の流れとプレイヤーの操作

通常ルームの戦闘は、次の順に進みます。ラウンド進行でプレイヤーが行う主な操作は「宣言」です。戦闘突入・ラウンド開始・戦闘終結はGMが操作します。解決表示は進行役（通常はGM）が進めます。

1. **戦闘準備中**：画面右側の列の状態表示が「戦闘準備中」のあいだは、ラウンドは始まりません。
2. **戦闘突入とラウンド開始**（GM）：GMが「戦闘突入」を行うと、状態表示が「戦闘中」になります。ラウンドを開始すると、駒の上にスロットが付きます。スロットの数字は、そのラウンドの速度値です。
3. **選択フェーズ**（プレイヤー）：自分のキャラクターのスロットごとに、スキルと対象を宣言します（4.2）。速い順を待つ必要はありません。
4. **解決フェーズ**（GM）：宣言がそろうと、GMが解決を始めます（4.3）。
5. **ラウンド終了**：解決が終わると、ラウンド終了時の処理が自動で行われます。次のラウンドはGMが開始します。
6. **戦闘終結**（GM）：GMが戦闘を終えると、結果が表示され、状態表示が「戦闘準備中」に戻ります（4.4）。

戦闘を始めても、HP・MP・FPは自動で回復したり0になったりしません。シナリオで回復などが指定されている場合は、GMの案内に従います。速度値の決め方、マッチと一方攻撃、ダメージ、FPの獲得は卓上ルール本の戦闘の章を参照してください。

### 4.2 宣言する

宣言は、選択フェーズのあいだに盤面のスロットから行います。宣言パネルの上部に「1 使用者」「2 スキル」「3 対象」の手順と、次に行う操作の案内が表示されます。

1. **使用者を選ぶ**：自分のキャラクターの駒のスロットをクリックします。宣言パネルが開き、そのキャラクターのスキルがカードで並びます。
2. **スキルを選ぶ**：使用するスキルのカードをクリックします。カードの一覧が、そのスキルの詳細（威力レンジ、コマンドなど）に切り替わります。
3. **対象を選ぶ**：対象にするキャラクターの駒のスロットをクリックします。自分を対象にするスキルや広域スキルでは、この手順は要りません。
4. 「内容を確認して『宣言』を押してください。」と表示されたら、内容を確認して「宣言」を押します。

- 使用者を選んだ後、スキルより先に対象を選ぶこともできます。その場合は、その対象に使えるスキルだけが表示されます。対象を変えたときに使えないスキルが選ばれていると、選択が解除されます。
- 使用コストが足りないスキルのカードは薄く表示され、選べません。HPを使用コストにするスキルも、HPが足りなければ選べません。「封印中」のスキルも選べません。
- 選んだスキルを変えるときは、スキル名の横の「↩」でカードの一覧に戻ります。
- 宣言した後でも、解決が始まる前なら、スロットを選び直して内容を変え、確定し直せます。画面のボタンは「宣言」または「再宣言」です。宣言済みのスロットは1回クリックすると、宣言した内容が入った状態で開きます。2026-10-19の実機記録のクリック種別による違いは、コード再照合により確定済み・選択途中の状態差と区別しました（出典・不足台帳§16のレビュー反映）。編集後は必ずもう一度確定します。
- 自分のキャラクター以外のスロットを開いた場合、ボタンは「閲覧」になり、宣言できません。
- 威力レンジは予想の幅で、ダイスを振った結果ではありません。

単体の行動は、互いのスロットが相手を対象にしていれば原則としてマッチになり、そうでなければ一方攻撃になります。引き寄せなどで対象が変わることがあるため、宣言後の矢印も確認してください。対象の決まり方の詳細は卓上ルール本と[B03](B03_SelectResolve_Spec.md)を参照してください。

即時発動スキルは左端の⚡から使用します。1キャラクターにつき1ラウンドに1回まで使え、確定時に使用コストと効果を処理します。通常のスロットは消費しません。次のラウンドが始まると、使用済み表示が解除されます。ただし、宝石の加護のスキルは1回の戦闘で1回までです。1度使うと、その戦闘が終わるまで一覧に表示されません。

### 4.3 解決を見る

宣言がそろうと、GMが解決を始めます。解決の表示を進めるのは進行役（通常はGM）です。担当以外のプレイヤーは表示を見て待ちます。

- 解決の始めに「戦闘開始」の表示が入ります。
- 解決パネルに、マッチ・一方攻撃・広域の結果が1件ずつ表示されます。威力は「レンジ → 実際の威力」の順に出ます。
- 一方攻撃では、受ける側のスキルは表示されず、「Xの一方攻撃」と表示されます。
- ダメージは「ダイス由来」と「効果由来」に分けて表示されます。効果由来のダメージは「亀裂」「破裂爆発」などの内訳名で表示されます。
- 非ダメージのスキルは、命中してもHPは減りません。命中時の追加効果（バフや状態異常の付与）は通常どおり処理されます。
- ログの「強硬攻撃」は、通常のマッチに敗れた後の専用の追撃です。回避の差し込みがあってもなくても「強硬攻撃」と表示されます。牽制や回避で止められた場合は、不発の理由がログに出ます。
- 解決によるHP・FPの変化やラウンド終了時の効果は、チャットのログで確認できます。

### 4.4 ラウンドの終わりと戦闘の終わり

ラウンドの解決が終わると、ラウンド終了時の効果（スキルの終了時効果、出身ボーナスなど）が自動で処理されます。

GMが「戦闘終結」を行うと、全員の画面に「VICTORY」「DEFEAT」「RETREAT」「INTERRUPTED」のいずれかが表示されます。通常キャラクターのHP・MP・FP・盤面の配置は保持され、召喚体と戦闘中のバフ・デバフ・付与スキルを除き、状態異常と荊棘重絡を0にして初期効果へ戻したうえで、状態表示が「戦闘準備中」に戻り、次の戦闘はラウンド1から始まります。

画面右側の列の一番上にある「戦闘記録」では、そのルームで終えた戦闘の結果、開始・終了時刻、完了したラウンド数、キャラクターごとの与えたダメージと受けたダメージを確認できます。記録の削除はGMだけが行えます。

### 4.5 アプリが自動で処理する効果

次の効果は、条件を満たすとアプリが自動で処理します。プレイヤーが操作する必要はありません。内容は卓上ルール本の該当箇所を正とします。

| 効果 | アプリの処理 | ルールの参照先 |
| --- | --- | --- |
| 出身ボーナス | ラウンドの開始時・終了時、攻撃時などに自動で適用。キャラクター詳細で出身とボーナス国を確認できる | 卓上ルール本「出身国ボーナス」 |
| 加速・減速 | 付与後1ラウンド待機し、1ラウンド有効。その間の速度値に加算・減算 | 卓上ルール本「速度値」 |
| マッチ勝利時のFP | 勝った側のFPを自動で増やす | 卓上ルール本「FPの付き方早見表」 |
| 防御と回避、回避どうしが向き合った場合 | 両方を不発として処理（使用コストは減らず、効果も発動しない） | 卓上ルール本の不発の説明 |
| 味方を対象にするスキル | 引き寄せの処理に参加しない。同じ陣営どうしで互いを対象にしても、マッチにならず一方で処理 | [B03](B03_SelectResolve_Spec.md) §10.6（卓上ルール本には未収録） |

### 4.6 探索パート

戦闘以外の場面では、GMが探索パートに切り替えます。駒を自由な位置に置け、背景画像が表示されます。

- **視点の移動**：背景の何もないところをドラッグします。
- **拡大・縮小**：マウスホイール、または探索画面の右下の「＋」「－」を使います。「⟲」で元に戻します（戦闘盤面の操作ボタンは左下）。
- **キャラクター詳細**：駒をダブルクリックします。
- **探索判定**：ドックの「🎲」（探索判定）でキャラクターと使用技能を選びます。使用する技能・ダイスの個数・目標値は、シナリオに従ったGMの案内を確認します。指定された個数を「ダイス数」、目標値を「目標値 (任意)」へ入力し、「判定を実行」を押します。ダイス数の初期値は2で、1個に固定するルールではありません。目標値が0なら成否は付かず、合計だけを表示します。候補は、配置済み・HPが1以上で、自分が所有するキャラクターです（GMは全員）。期限切れの召喚体は候補に入りません。
- **簡易編集**：ドックの「📝」からHP・MPなどを簡易的に編集します。

探索判定の式と目標値は卓上ルール本の「判定ルール」を参照してください。

目標値が正なら、合計が目標値以上で「SUCCESS」、未満で「FAILURE」を表示します。目標値0では成否を表示しません。成否は許可済みの太字書式を使い、キャラクター名・技能名はHTMLとして解釈しません（D14、作業B8）。

### 困ったとき（戦闘・探索を操作する）

| 症状 | 確かめること |
| --- | --- |
| スロットが表示されない | 状態表示が「戦闘中」で、ラウンドが始まっているか。キャラクターが盤面に置かれているか |
| スロットを押しても宣言パネルが開かない | 自分のキャラクターのスロットか。解決が始まった後ではないか |
| スキルのカードが選べない | 使用コスト（FP・MP・HP）が足りているか |
| 宣言ボタンが押せない | 対象のスロットを選んだか |
| 解決が進まない | 解決表示は進行役（通常はGM）が進めます。進行役の操作を待ちます |

## 5. セッションの後

### 5.1 成果を反映する

持ちキャラから追加したキャラクターは、セッションの後に、キャラクター詳細の「⚙」から「成果を反映」を行うと、入力した獲得経験値とアイテムが持ちキャラへ加算されます。GMに報酬を確認してから入力してください。未実装モードに対する条件分岐はF01 Part 9で扱い、一般PLの手順には含めません。

- 反映は、キャラクターの持ち主またはGMが行えます。
- 「獲得経験値」へ点数を入力し、アイテムがある場合は「獲得アイテム」へ`item_id:個数`をカンマで区切って入力します。IDはGMに確認します。
- ルーム内のコピーごとに1回だけ反映できます。経験値0・アイテムなしでも反映済みになるため、入力内容を確かめてから押してください。成功ログの後、設定メニューを開き直すと「このセッションの成果は反映済みです。」と表示されます。
- 反映するのは入力した報酬です。ルーム内で変化したHP・MPや所持品全体を保存した持ちキャラへ丸ごと上書きする操作ではありません。

### 5.2 持ちキャラを成長させる

ロビー左下の「マイキャラクター」で、成長させるキャラクターの「🌱」（成長）を押します。

- 経験値で戦闘スキルを、通過点で輝化スキルを取得できます。それぞれの予算は別に管理されます。
- 種別・スキルを選び、効果と取得コストを見て「＋ 予定に追加」を押します。予定から外すときはスキル名の横の「×」を押します。
- 消費予定と残り予算を確認して「成長を適用」を押します。成功すると一覧が再取得され、成長パネルは閉じます。一覧に表示された残り経験値・残り通過点を確かめます。
- 持ちキャラを成長させても、すでにルームへ追加したコピーへは自動で反映されません。次回の投入に成長後の持ちキャラを使います。
- 筋力・生命力・体格・精神力・敏捷を、経験値で直接上げることはできません。
- キャラ作成ツールで編集し直す場合も、能力値を経験値で上げる手順にはなりません。編集画面の予算表示には取得済みスキルの分が含まれるため、残りの経験値とは区別してください。

成長のルールは卓上ルール本の「継続と成長」を参照してください。

### 5.3 ルームから退出する

成果反映を確かめたら、画面上部の「🏠」（ルーム一覧に戻る）を押し、確認画面で「戻る」を選びます。ロビーの一覧へ戻れば退出完了です。

- 退出しても、ルームへの参加資格とルーム内のキャラクターは残ります。参加済みルームの「入室」から戻れます。
- ルーム一覧へ戻る操作は、アカウントのログアウトとは別です。
- 2026-10-19：区切り5で成長・退出・再入室もブラウザ確認済み。予定の取り消し・予算超過拒否・戦闘/輝化スキルの同時取得と一覧更新、退出後の参加資格・キャラクター保持を確認（出典・不足台帳§16）。

### 困ったとき（セッションの後）

| 症状 | 確かめること |
| --- | --- |
| 「成果を反映」が表示されない | 持ちキャラから追加したキャラクターか |
| 「反映済みです」と表示される | そのセッションの成果は反映済みです |
| 成果反映で「この操作を行う権限がありません。」と表示される | 自分のキャラクターか。以前のコピーで拒否される場合はGMに代理反映を相談します |
| 成長に必要な経験値・通過点が足りない | それぞれの残り予算と消費予定を確認し、予定の「×」で外します |
| 成長後もルーム内のスキルが変わらない | ルーム内のコピーには自動同期されません。次回は成長後の持ちキャラから追加します |
| ルーム一覧に戻れない | 接続を確認してから「🏠」を押し直します |

## 付録A 共有された戦闘専用プリセット

- 公開、GM共有、または自分へ個別に共有されたプリセットは、与えられた権限の範囲で閲覧できます。
- 閲覧者は内容の確認、複製、通常のJSON出力を行えますが、元のプリセットの編集・削除・再共有はできません。
- ルームでプリセットを戦闘に配置できるのは、そのルームのowner・gmです。通常のプレイヤーには、戦闘の表示と操作に必要な情報だけが配信されます。
